# 2026-11-07 並列開発の進展と残条件

[English](en/development-2026-11-07.md)

前回のPR251をmainへ統合し、公開CIまで成功した状態から、別作業場所で次の実装と独立監査を進めた。既存データや過去の失敗ログを上書きしない。

| 項目 | 今回仕上げる範囲 | 残る条件 |
| --- | --- | --- |
| 別試験片への予測 | 原文SHAを固定した保存CLI、正式stdio MCP、独立した単位変換・誤差検算 | 実測校正、物理的な試験片の独立性、材料への適用 |
| SLS係数からProny材料点への往復 | 明示K、せん断係数・時定数の変換、有限ランプ・時間刻みの収束、保存実行 | 完全な有限ひずみ一致ではない。実験比較・構造経路は未完 |
| 流体・板の接線方向連成 | 実チャネルソルバーの時間平均力とmidpoint板、仕事・散逸・運動量の独立検証、保存実行 | 法線・圧力・ALE・曲面・非線形・画面経路は未完 |
| Tet10の保存解析ジョブ | 明示次数2、Worker/別プロセス/正式MCP、全中間節点とGauss点の保存、閉式参照 | 単一箱・全面条件の限定。一般形状、比較、表示、点取得は未対応 |

保存実行は原文・設定の版、単位、計算方法、上限と成果物SHAを保持する。取消・期限切れは所有Workerの実終了を待ち、完成前の成果物を公開しない。Worker出力をCLI/MCPのJSONへ混入させず、既存ファイルを上書きしない。これらはソフトウェアの実行・検証機能であり、実測値や校正記録を作り出すものではない。

大項目は全197件、released159・building34・checking4・queued0、残38件。今回の限定機能だけで親タスクを完了へ変更しない。P5BはTet10結果の共通比較経路と設計反復の受入を残す。PRINTMEASURE1/2/3・PRINT2・FINITEVISCO1は、実機・実スライス・実測・校正など各既存受入が必要である。他の大項目にも一般形状・対応物理・性能計測・実接続などのソフトウェア/実検証の残件があり、全38件が外部データ待ちという意味ではない。

個別の実行環境、成功・失敗・修正、原本ログは `docs/evidence/2026-11-07-*` に分けて記録する。全体検証・公開の最終判定は対応PRの固定headのCIで確認する。合成例の数値一致を物理精度や校正の証明と扱わない。
