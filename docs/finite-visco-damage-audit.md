# 局所スカラー損傷の独立監査・修正（2026-11-04）

[English](en/finite-visco-damage-audit.md)

基準 `d8214ad` の指示100の合成材料点を監査し、状態偽造、入力getterの実行、指数則の桁落ちを修正した。95のPRF-J2・88のHencky Prony・72の一軸Prony本体、旧試験と10月29日の証拠は変更していない。

以前は、発行済み状態を展開し、散逸を−100に変えて再凍結したレコードが受理され、次の出力も負の散逸になった。現在はこのmoduleが発行した状態だけをWeakSetで識別する。状態は凍結済み・プロセス内限定で、JSON/structured cloneや再構成レコードからの再開は拒否する。WeakSetは過去状態を強参照せず、状態列全体を保持しない。型宣言にも不透明な状態ブランドを付ける。

パラメータの展開と下位modelへの委譲の前に、通常のデータプロパティ・密な通常配列を検査して複製する。分岐8、区間64、合計4096ステップ、Fの3×3を先に制限し、getter・配列独自map/iterator・疎配列を実行せず拒否する。下位modelの物性・伸び・J・dt/τ・時間上限は引き続き適用する。

指数 `x=max(0,(r−Y0)/Yf)` に対して損傷を `−expm1(−x)`、応力・貯蔵エネルギー・粘性/塑性増分の係数を `exp(−x)` とする。`1−exp(−x)` が消していた約1.25e−18の損傷を保持し、`1−d` から残存係数を再構成しないことで、x=35で約5.65%あった残存応力の相対誤差を除く。dが浮動小数点で1へ丸まる強い損傷は、既存の `d<1` 契約に従って明示拒否する。要素削除や完全破断へ読み替えない。

独立試験は他の構成則moduleの出力を正解値として使わない。球状変形 `F=aI` のHencky閉形式 `Y=9e6(log a)²`、`τ_eff=6e6 log a`、`J=a³`、履歴最大値と台形の損傷散逸を検算する。側面無拘束・十分に緩和した合成一軸例は `ν=2/7`、`E=18e6/7 Pa` の閉形式から応力・エネルギーを検算する。既存4件と新規5件を含む関連46件が成功し、35宣言の型検査も成功した。
