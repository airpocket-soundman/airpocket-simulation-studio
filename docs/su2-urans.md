# 非定常の外部流れ：試験的な接続

既存のSU2ネイティブ接続（PR #7）に依存するドラフトです。ブラウザWASM / WebGPUによる流体計算ではありません。

## 入力と操作

承認済みケースの `kind` を `unsteady-incompressible-rans-sa` にし、`timeStepSeconds`、`timeSteps`、`outputEvery` を明示します。`maxIterations` は各物理時刻の内側反復上限です。SA・標準壁関数・SI単位は既存接続と同じです。均一な初期流れから開始し、定常結果からの再開は未実装です。

実行設定は起動時固定です。時間刻み >0〜1秒、2〜200ステップ、内側反復最大500、保存間隔は正の整数、保存フレーム最大41、登録出力合計256 MBを上限とします。ホストの実行タイムアウトは900秒です。出力容量の検査は計算終了後であり、ディスク使用量の実行中制限ではありません。

- API: 既存の開始・監視・中止に加え `GET /jobs/{id}/frames/{index}`。完了・終了確認済みの結果だけを取得します。
- ブラウザ: `nativeFlowApi.getFrame(index, jobId)` / `showFrame(index, jobId)`。時刻選択・再生/停止を追加しました。再生速度は表示都合であり実時間とは異なります。
- MCP: `studio_native_flow_result` に任意の `frame`（0始まり）を追加。既定応答はフレーム一覧、`field` を指定すると選択時刻のデータを最大200件ずつ返します。

フレームにはSU2の時間インデックスと秒を保存します。試験の `Cur_Time` とインデックス×時間刻みが一致することを確認しました。フレーム取得時に登録VTUのサイズ・SHAを再検査します。JSON転送そのものの別ハッシュは提供しません。既存の最終結果JSONのハッシュ検査は維持します。

## 確認結果と限界

同じ牛・空気5 m/sで6ステップ、刻み0.02秒、内側12反復を実行しました。SU2表示時刻0〜0.10秒の6フレームを取得し、直接実行と接続実行の全VTU・履歴ハッシュが一致。実Studio画面で接続、時刻変更、画像取得を確認し、MCPの指定時刻ページ取得も確認しました。試験記録は `docs/evidence/2026-10-15-cow-urans-smoke.json` にあります。

ただし未収束であり、起動試験です。壁関数警告は残り、途中の残差も悪化しています。添付GIFはこの起動過程の表示であり、実際の乱流や発達した後流の再現を証明しません。全時刻の内側収束を認定していないため、非定常結果の `numericallyConverged` と `allTimeStepsConverged` は常に false とします。

各時刻40反復の先行試験は180秒で打ち切りました。短時間試験の完走を理由に精度条件を満たしたとは扱いません。壁面メッシュ・時間刻み・反復数・計算区間の検証が次の受入条件です。

未実装: 計算中の場データ取得、流線・渦度・逆流専用表示、ブラウザ内MP4/GIF出力、長時間の渦放出検証、GPU流体計算。GIFは検証用スクリプトで保存時刻を順に描画して作成しました。

SU2設定の根拠: https://github.com/su2code/SU2/blob/v8.5.0/config_template.cfg

## 内側反復・壁関数の感度試験（2026-10-15）

同一牛・同一メッシュ・dt=0.02秒・6時刻を比較。各時刻12→60反復で、0.10秒の圧力残差は−2.919→−5.392、最大速度成分残差は−2.176→−3.680となった。ただし速度目標−5は未達、壁面警告の最終対象点は215→220。牛周辺 x=[−1.5,1.8]、y=[−0.7,0.7]、z=[0,2] m の5681節点で、圧力差RMS=1.450 Pa、速度ベクトル差RMS=0.295 m/s。体積重みなしの節点比較であり、正解に対する誤差ではない。

公式チュートリアルの対処候補に従い、壁関数の内部上限を1000反復に増やした別試験も実施。緩和係数0.2では最終警告1210点、0.5では233点となり解消しなかった。これらを推奨設定や既定値に採用しない。

承認済み入力に任意の `wallModelNumerics: {maximumIterations, relaxationFactor}` を追加可能。整数200〜2000、有限値0.05〜1、SAのみ。壁関数の数値反復設定であり物理モデルや許容誤差の変更ではない。capabilitiesに範囲を返し、未知のキーと範囲外は拒否する。

次の優先は壁面近傍メッシュと壁面処理の適合確認。時間刻み半減・メッシュ独立性・発達した後流の検証は未実施。証跡: `docs/evidence/2026-10-15-cow-urans-sensitivity.json` と同日の比較PNG。
