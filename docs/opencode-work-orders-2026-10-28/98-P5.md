# 98 P5 — 設計ループ非収束の原因切分けと収束した再実行（Tet10）

## 開始条件

[共通指示](../opencode-work-orders-2026-10-23/00-COMMON.md)の書式・禁止事項に従う。基準main `c3a73e6`。前作業[97](97-P5.md)の続き。親P5とは区別する。`src/progress.json` と共有roadmapは編集しない。MCPサーバー（`scripts/studio-mcp.mjs`）は変更しない。

## 現状（着手前の確認）

97は合成ブラケット t=2/3/4/3.9 mm の全案が未収束（最細2水準の最大変位変化 14〜45%）で、選定 t=3.9 mm を設計判断に使えないと記録した。

## 原因の切分け

| 候補 | 判定 | 根拠 |
|---|---|---|
| ソルバー反復未収束 | 否 | `src/fem-core.js` の `pcg` は残差 < 1e-8 でなければ `Solver did not converge` を投げる。97の全ジョブはsucceeded |
| 拘束不足・剛体モード | 否 | 根元面z=0全拘束。拘束不足なら `pcg` が `Unconstrained or ill-conditioned` を投げる |
| メッシュ品質・反復上限 | 主因でない | 同じMCPメッシュをTet10で解くと h=2 から変化0.1%未満（下表） |
| **Tet4曲げロッキング** | **主因** | 板厚方向1〜4要素の定ひずみ四面体。h=1で要素上限30000付近のためTet4細分では漸近域に届かない |

判定は閾値緩和でなく要素次数で行う。閾値は97と同じ5%。

## 選定した有界な一歩

- `src/tet10-elastic.js`（既存の直辺Tet10）に節点荷重 `forces:[{node,vectorN}]` と、一様面荷重の整合節点力 `tet10UniformFaceForces`（6節点三角形: 頂点0・中間節点に1/3）を追加。既存挙動は不変。
- 回帰試験 `tests/tet10-cantilever-force.test.mjs`: 荷重総和・中間節点のみ・不正入力拒否、先端荷重片持ちでTet10がTimoshenko梁に下から近づき（0.95→0.97）、同一メッシュのTet4は0.6未満（ロッキング）。
- `scripts/experimental/p5-bracket-converged-loop.mjs`: 97と同一の合成条件・MCP手順（作成・条件・材料・来歴・事前検査・メッシュ・Tet4解析）で、MCPが書いた同じメッシュをプロセス内Tet10で再解析し、97と同じ判断規則を**全入力収束時のみ**適用。第2周案も収束かつ目標内のときだけ選定。

## 受け入れ条件

1. 4案×3水準の全ジョブsucceeded・provisional=true、事前検査allowed、入力版4つが異なる。
2. 全案Tet10収束（変化 < 5%）、PCG残差 < 1e-10、荷重面積=先端面積、Tet10 > 同メッシュTet4。
3. 収束解がTimoshenko梁の0.9〜1.05倍。決定案が規則どおり（exact ≤ next < exact+0.1）で第1周と異なる。
4. 焦点試験が証拠とscript・`tet10-elastic.js` のhash整合を検査。
