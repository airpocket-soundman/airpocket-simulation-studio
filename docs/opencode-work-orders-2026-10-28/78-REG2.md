# 78 REG2 — 保存済み円筒・円錐パッチの逆方向宣言照合

共通: 読み取り専用 `docs/opencode-work-orders-2026-10-23/00-COMMON.md` に従う。これは計画書であり、REG2 親受入の完了・公開を示さない。

## 具体的問題

球面パッチは「寸法内にある三角形がパッチ宣言 (`patchConditions`) を持つこと」も検査するが、円筒・円錐パッチは宣言済み三角形が寸法内かだけを見る。
保存ケースで寸法内の三角形1枚の宣言を外し、`meshAreaMm2` を合わせて改変すると、CAD面積との3%許容内で検出されず荷重領域が黙って欠ける。

## 変更範囲

変更可: `src/cylindrical-cad.js`、`tests/cylindrical-cad.test.mjs`、`tests/conical-wiring.test.mjs`、本指示書、証拠JSON。
禁止: 形状生成・面積式・許容値（3%、1e-7）の変更、球面/平面側、UI、`src/progress.json`、roadmap。

## 番号付き実装と受入

1. 反例 test を先に作り失敗を確認: 円筒（size 4, 2）で寸法内の宣言三角形1枚の宣言を外し、`meshAreaMm2` を再計算値へ合わせた改変ケースが拒否されること。
2. `validateCylindricalMesh` に逆方向照合を追加: 3頂点が寸法内、重心を曲面へ投影した点も寸法内、かつ三角形法線が曲面法線と45度以内なら宣言必須、それ以外は宣言禁止。法線条件で端面（円板）の縁に3頂点が乗る三角形を除外する。円錐は `radiusAtMax` の勾配で曲面法線を傾ける。
3. 未改変の円筒（90度扇形・全周帯・回転STEP）と円錐生成メッシュが従来どおり受理されること。
4. 円錐でも同じ改変が拒否されること。
