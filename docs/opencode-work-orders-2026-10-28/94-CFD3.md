## 選定した有界な一歩

87の残候補(a)。`src/euler-1d-muscl.js` を追加する。

- 原始変数（ρ,u,p）の区分線形再構成。制限関数は none（中心差分、滑らか解専用）/ minmod / van Leer。
- 時間積分はShu-Osher SSP-RK2、CFL既定0.45（2次は≤0.5のみ許可）。order=1指定で87と同等の一次スキーム。
- 境界: 周期（両端面流束を同一値にし流入を厳密0）、透過、反射壁（2ゴーストセル、質量・エネルギー境界流束を厳密0）。
- 滑らかな基準: 密度波 ρ=1+0.2 sin(2πx)、u=1、p=1 の周期移流。Eulerでは厳密に平行移動するため、1周期後のセル平均厳密値（解析積分）と比較する。
- 単位は無次元。合成入力であり実在物体・実測値ではない。

## 受け入れ条件

1. 滑らか解（N=32→256）: 無制限MUSCLの観測L1密度次数が1.95〜2.1。minmod >1.8、van Leer >1.9（最細対）。一次は<1.05。N=256でminmod誤差 < 一次の1/10、van Leer < minmod。
2. Sod t=0.2 N=400: 2次minmodのL1密度誤差 < 一次の1/2。
3. 保存量収支: 周期・透過・反射壁とも相対収支誤差 < 1e-13。周期は境界流入が厳密に0、反射壁は質量・エネルギーの境界流入が厳密に0。
4. 正値性: Toro試験2（123問題）で2次minmodの密度・圧力が正。再構成面状態が非正なら例外。
5. 不正な格子数・CFL・次数・制限関数・流束・境界・初期値関数・非物理初期状態、step上限、時間予算超過は例外。
6. 証拠JSONにbase SHA、solver/共有流束/script hash、環境、コマンド、全行の実測値、未確認項目を保存。
