# 3MF・G-codeの読込と確認

[English](en/printing-import.md)

v0.43の「3Dプリントデータを確認」は、3MFの元形状・造形設定・プレート内のG-code、または単独のG-codeをブラウザ内で読み込みます。読込結果は専用の確認ビューとJSON書出しで使えます。構造解析の外形・材料へ適用する操作は、積層・インフィルの材料校正と別タスクで接続します。

## 操作

1. 「01 モデル」の「3Dプリントデータを確認」を開きます。
2. 3MFまたはG-codeを選びます。
3. 「元の形状」と「造形プレート」を切り替えます。各プレートは「全ての層を表示」を解除して層ごとに確認できます。ビュー内で回転・拡大できます。
4. 層高、インフィル、壁、フィラメントなどの収録された設定を確認します。
5. 「読込結果を書き出す」またはテキスト欄から、形状・設定・押出経路をJSONで受け取れます。

設定値はスライサーに記録された値です。フィラメント名やインフィル率だけから、成形品のヤング率・異方性・強度を生成しません。元形状とプレート経路の座標も自動で同一視しません。多プレートの配置や造形時の変換は別途確認が必要です。

## 3MFの対応範囲

[3MF ConsortiumのCore仕様](https://github.com/3MFConsortium/spec_core/blob/master/3MF%20Core%20Specification.md)に沿って、メッシュ、部品ツリー、build/componentの変換と単位を読み込みます。Production Extensionの別モデルファイル参照にも対応。鏡映変換では三角形の向きを反転し、部品の向きを保持します。

ZIPと単一ディスクZIP64、保存・DEFLATE形式に対応します。CRC、ヘッダー、参照、サイズを確認し、外部URLからのデータ取得は行いません。未知の必須拡張、循環部品参照、壊れた頂点番号、複数ディスク、暗号化、ファイル間の単位混在は拒否します。テクスチャ、ビームラティス等の拡張を表示する機能ではありません。

Bambuの`Metadata/project_settings.config`、`model_settings.config`、`plate_*.gcode`を読み込みます。部品別設定はobject ID・key・valueで書出しに残します。格納名は[BambuStudio公式ソース](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/Format/bbs_3mf.cpp)を確認しています。未スライスの3MFでは経路がないことがあります。経路だけのパッケージでは元の形状は生成しません。

## G-codeの対応範囲

G0/G1の直線移動、G90/G91、M82/M83、G20/G21、G92、tool指定を処理します。押出指令が正で、移動開始・終了のXYZを確認できる経路を取り出します。引き戻しを解消した部分と、その場のパージは造形の押出量から除外。部分的に引き戻しを解消しながら移動する場合は、Eの指令量に比例した位置から経路を記録します。実際の圧力・流量の時系列を再現するモデルではありません。

ホーム復帰・測定後は、座標が明示されるまで位置を確定しません。円弧の移動だけの区間はプレビューから除外し、円弧の押出は拒否します。未対応の座標系変更を推測しません。ファームウェア補正、機器動作、工具交換の実物挙動は再現しません。Bambuの条件分岐内の経路は`conditionalDepth`を付けた候補経路として記録し、どの分岐が実行されたかは判断しません。

`TYPE`/`FEATURE`、層番号、設定コメントを保存します。層番号がない場合は終点Zから表示を分類します。非平面造形の層構造を自動で復元するものではありません。経路数・押出量は指令に基づく値で、実際の造形体積や質量の保証値ではありません。G-codeの指令をプリンターへ送信する機能はありません。

## 上限と検証

ファイルは3MF 50 MB、G-code 25 MB以下。圧縮展開はパッケージ全体150 MB・一部80 MB、XMLは25 MB、設定JSONは5 MB、1000ファイル、最大100表示部品・20万三角形・20プレート・合計20万経路です。CPUで読み込むため、大きいファイルは画面の応答が遅くなることがあります。ブラウザごとの性能検証は別項目です。

参照テストは単位、座標・押出モード、G92の連続性、引き戻し、部品変換、鏡映、Production参照、保存内容、CRC、ZIP64と不正データを確認します。自作参照は1形状・12三角形・2層・12経路・押出指令12 mm。画面では読込・層切替・書出し・拒否・日英表示を検証します。

2026-10-14には、BambuStudio公式の`pa_pattern.3mf`（1形状・12三角形）とZIP64の`flowrate-test-pass1.3mf`（9形状・6920三角形）をローカル読込で確認しました。これらは経路のない校正用プロジェクトです。全てのBambuバージョン・機種・3MF拡張の対応保証ではありません。

開発用: `node scripts/print-fixtures.mjs`で参照ファイルを`.qa`へ生成し、`node --test tests/print-import.test.mjs`で共通読込を検証できます。画面APIは`window.printImportApi.loadGcode(text)`、`load3mf(Uint8Array)`、`getDocument()`です。
