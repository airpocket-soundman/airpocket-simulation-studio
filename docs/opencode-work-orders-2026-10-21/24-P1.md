## 番号付き実装と受入

1. top-level `planarRegion` / `cylindricalRegion` と `conditions/<i>/...` の既存 spec を列挙。球面と同じ厳密 lookup 方針にし、未知 key の推測はしない。
2. 平面 position/min/max/frame.origin は mm、frame.u/v は 1、rotationDegrees は deg。axis は座標軸 index であり長さではない。単位を付けるなら dimensionless 1 とする。
3. 円筒 origin/radius/tolerance/axialMin/axialMax、存在する radiusAtMax は mm。axis/reference は 1、startDegrees/sweepDegrees は deg。mesh index・exactCad・legacyScale 等へ mm を付けない。
4. 配列そのものと各 scalar pointer、condition 内の同 descriptor、inputProvenance の対応 value で単位が一致する test を追加する。別の region に同名 key があるだけでは単位を付けない。
5. 合成例: planar axis=2, position=10 mm, min=[0,0] mm, max=[20,30] mm。円筒 origin=[0,0,0] mm, radius=12 mm, axialMin=-10 mm, axialMax=10 mm, tolerance=0.3 mm, start=315 deg, sweep=90 deg。正規 validator を通る spec を使う。
6. paging offset/limit を跨いでも同単位、JSON保存復元後も値/revision/hash不変、inspect 前後 input 不変を確認する。単位変換は行わない。
7. 実 Chrome はこの pure metadata 受入の必須条件ではない。実行しなければブラウザ/MCP end-to-end 未確認と記録する。CAD 再メッシュ不要。
