# 印刷材料用 引張・圧縮試験機の要求仕様と機器プロファイル

[English](en/printed-test-machine.md)

2026-10-28、指示73 PRINTMEASURE1の最初の一歩。[企画](printed-material-measurement.md)の「引張と圧縮の測定装置」を、自作機と販売機が共通に満たす要求と、機器を記述するデータ形式へ落とした。機械・電気設計、部品選定、販売方式と価格は未決定であり、本書は装置の性能や精度を示さない。

## 要求仕様（自作機・販売機共通）

| 項目 | 要求 | 未決定 |
|---|---|---|
| 試験モード | 引張・圧縮の一方または両方を宣言し、各モードに治具（つかみ/圧縮盤）を1つ以上持つ | 治具形状、試験片形状との対応（PRINTMEASURE2側） |
| 荷重検出 | ロードセルの定格容量を宣言する。型番は任意（未記載はnull） | 容量、分解能、精度等級 |
| 変位検出 | クロスヘッド変位と標点変位を区別して宣言する。工学ひずみには標点変位源が必要 | 伸び計・映像等の方式と精度 |
| 停止 | 荷重・ストローク・速度の制限を装置側で成立させる（ブラウザ/ホストのみの停止は不可）。荷重停止値は定格容量以下 | 停止の応答時間と検証方法 |
| 装置剛性 | 未測定または報告値（mm/N、根拠付き）として記録する。クロスヘッド変位からの補正は本形式では行わない | 測定手順、補正法 |
| 校正 | 荷重・変位の校正を未検証または報告（根拠文字列付き）として記録する。報告も第三者確認ではない | 校正手順、合否基準、周期 |
| 識別 | 機器ID、版、ハード版、ソフト版。測定datasetの `instrument` と一致させる | — |

## 機器プロファイル形式（schemaVersion 1）

`src/printed-test-machine-profile.js` の `validatePrintedMachineProfile(object)` が検査し、N・mm・mm/sへ正規化して返す。型は `src/contracts/printed-test-machine-profile.d.ts`。`origin` は diy/vendor、`provenance` は synthetic/declared。declaredは所有者の申告であり、`accuracyVerified` は常にfalse。合成プロファイルは校正・剛性の報告を持てない。単位は文字列で明示し、欠損・余分なfield・非有限値・重複ID・治具のないモード・ホスト側停止・定格を超える荷重停止を拒否する。

`checkDatasetAgainstMachineProfile(profile, dataset)` は[測定dataset取込](printed-measurement-dataset.md)の正規化結果と照合し、例外ではなく所見の一覧を返す: 機器ID/ハード版/ソフト版の不一致、プロファイル未校正なのにdatasetが校正報告、標点変位源なし、速度・荷重が装置制限超過、提供しないモードの荷重符号。荷重の符号は本照合で正=引張・負=圧縮と仮定する（dataset契約自体は符号を定めない）。所見が無いことは測定の妥当性や精度を意味しない。

## 範囲外

実機の設計図・部品表・ファームウェア、通信方式（ブラウザ直接/ログ取込）、画面・MCP接続、装置剛性補正の適用、試験片とBambu出力（PRINTMEASURE2）、同定（PRINTMEASURE3）。回帰試験の数値はすべて合成で、実在機の能力ではない。
