# Retained explicit indexed opening-surface boundary

[日本語](../retained-opening-surface.md) / [Existing confirmation and missing providers](fluid-domains.md)

`createRetainedOpeningSurfaceProvider()` retains only a caller-declared open indexed triangle surface. Original node IDs, node order, triangle order and winding are privately copied without conversion. It binds a content SHA-256, caller sourceIdentity and monotonic generation. It does not reconstruct nonindexed display geometry, weld coincident IDs, infer normals, remove port faces, build OCC lids or generate meshes. No solver/UI/API/MCP/project-persistence connection is added.

Call `replace({units:'mm',topologyIntent:'open-indexed-surface',sourceIdentity,mesh:{nodes,triangles,toleranceMm}})` to obtain a lease. `confirm(lease,{confirmed:true,capId,candidate,outwardNormal,interiorPointMm,enclosure})` uses an explicitly chosen candidate and outward normal. `release(lease)`, `clear()` and terminal `dispose()` invalidate ownership. The Japanese example shows the complete call shape.

Only ordinary data objects and dense ordinary Arrays are accepted. Unknown fields, accessors, sparse/decorated/subclass/typed arrays and nonfinite coordinates are refused without invoking getters. The entire input is owned before hashing awaits, so later caller mutation cannot split identity and geometry. sourceIdentity is a nonempty caller identity string up to256 characters, not a signature or authenticated CAD provenance.

**Provider-specific limits before detector work:**512 nodes,1024 triangles, coordinates within±1e6mm, tolerance1e-9..1e3mm, canonical input1MiB, graph20000 values/depth8, strings256. The original detector has no capacity gate; this small envelope bounds component/loop and cycle-canonicalization work.1MiB is a simultaneous ceiling, not a guarantee that an input can consume that many bytes. These limits do not prove general shape accuracy or whole-process peak RAM.

contentRevision is SHA-256 of canonical UTF8 JSON for all `{units,topologyIntent,sourceIdentity,mesh}` fields. Only dictionary keys are sorted: all IDs/order, unused nodes and tolerance remain bound. It is not interchangeable with sourceHash, projectRevision or a CAD mesh version. The lease exposes frozen detector reports, not the private mesh. Closed shells retain zero candidates; seams and unhealthy components retain refusal reasons. Caller open intent is not a topology or health proof.

At most two replacements may be in flight. A slot is reserved before snapshotting; a third request is refused with `OPENING_SURFACE_PENDING_LIMIT` before reading input getters/arrays, without changing current/generation. Finally releases the slot after malformed snapshots, successful/failed hashes and replaced requests. Clear/dispose never falsely reset unresolved-hash slots; they remain counted until their actual promises settle. This bounds parallel ownership, not caller-held reports or the entire JS heap in bytes.

A validated replacement immediately revokes the previous lease; current is null while hashing. Only the latest generation may commit. Late responses, ABA and clear invalidate pending results with `OPENING_SURFACE_REPLACED`. Malformed replacement inputs leave the current lease/pending request unchanged. Hash failure uses `OPENING_SURFACE_HASH_FAILED` and never restores an old lease. Clear invalidates pending work; release accepts only the current lease; dispose is idempotent, revokes pending/current work and refuses later operations with `OPENING_SURFACE_DISPOSED`. Revocation deletes old geometry associations from the internal WeakMap rather than retaining an ancestor history.

Only the exact object issued by the same provider is accepted. Clones, JSON restores, foreign-provider and stale leases use `OPENING_SURFACE_STALE_LEASE`. Confirmation passes exact retained geometry/tolerance to the existing `confirmOpeningCandidate`, which re-extracts and compares the complete candidate. Generation supplies meshVersion; existing cap validation checks ID, explicit unit outward normal, seed and enclosure. Current ownership is checked before/after synchronous confirmation, and output is frozen. Candidate winding never determines physical outward direction.

[Evidence](../evidence/2026-10-26-retained-opening-surface.json) covers independent hashing, input mutation, races, ABA, lifecycle, seams/closed/unhealthy reports, limits and types. A product indexed-input acquisition/persistence contract and atomic UI append remain absent. This does not complete CFDPORT1 or general CAD opening support.
