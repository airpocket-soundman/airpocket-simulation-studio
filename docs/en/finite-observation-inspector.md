# Final synthetic-observation comparison UI

[日本語](../finite-observation-inspector.md) · [Comparison input contract](finite-visco-observation-comparison.md) · [History inspector](finite-history-inspector.md)

Within Inspect finite material-point input history, enter history JSON and expand Compare final synthetic observation (optional). Paste observation JSON and press Compare final synthetic observation. The existing Inspect history remains independently usable with an empty or invalid observation field. Ctrl/Command+Enter in the observation field compares; in the history field it retains replay-only behavior.

Load paired synthetic comparison example **replaces both inputs** with the explicit public/examples/finite-visco-comparison-history.json and finite-visco-final-synthetic-observation.json texts. They are not measurements. Hydrostatic F=1.01I, K=2MPa, a1s ramp and2s hold have E=.01005I, S=60300I Pa, free energy/work909.0225 J/m³-reference and zero dissipation. The observation declares synthetic offsets S11+25Pa, energy+2 and cumulative dissipation+1 J/m³-reference. These independently perturbed quantities illustrate differences, not a joint physical experiment. Small rounding differences are not hidden.

One call to unchanged compareFiniteViscoFinalObservation in the owned worker replays from I/Z0 and compares only the final checkpoint. The existing boundary requires exact raw/canonical history identities, parameter revision, final time, units and synthetic/provisional/uncalibrated provenance. Even whitespace changes history raw identity; no time tolerance, interpolation or nearest point is introduced. Hashes are not signatures, origin authentication or calibration guarantees.

The UI displays observed-minus-replayed3×3 second Piola–Kirchhoff S signed differences and maximum absolute component difference in Pa, plus separate signed/absolute free-energy and cumulative-dissipation differences in J/m³-reference. It does not combine scales, set pass thresholds, fit, divide into relative percentages or declare calibrated/pass. Input/observation/parameter hashes and time accompany results. Origin description renders as plain text clipped to240characters, not experimental provenance evidence.

Each input is at most1MiB (2MiB combined); history remains4096steps and comparison one final point. The same single owned worker,10-second watchdog, cancellation and disposal are used. Editing either input clears old results and invalidates work; direct value changes are checked on response and generations block ABA. Completion/refusal/errors/watchdog terminate the owned worker. No hard wall-clock guarantee during suspended JavaScript or complete OS-resource release is claimed.

Per-request-kind response validation refuses borrowed summaries, primitives, sparse/decorated matrices, nonfinite values, wrong units/calibration flags, extra pass/state fields and inconsistent absolute differences. Rejected histories show only failed/completed step information, without comparison numbers. All rendering uses textContent. Project/material/cases, structural solvers, saved schema, MCP methods/scopes and progress status remain unchanged.
