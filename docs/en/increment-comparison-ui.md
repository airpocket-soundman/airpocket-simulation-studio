# Compare increment curves

[日本語](../increment-comparison-ui.md) / [Single-curve UI](increment-curve-ui.md) / [Shared curve artifacts](increment-curve-export.md)

**Compare increment curves** validates 2–4 raw bundles and shows two static plots in one SVG: force–gauge extension (mm, N) and engineering stress–strain (strain 1, stress Pa). Colors and legends distinguish series. These compare independent linear-elastic solves; they are not true stress or plastic/viscoelastic state histories.

Start with **Save reference A** and **Save reference B**, select both downloaded JSON files together, then press **Validate and compare curves**. A is a single Tet4 with E=1e9 Pa and 0/10 N, failed 15 N, then 20 N; B uses E=2e9 Pa and 0/20 N, failed 30 N, then 40 N. Every successful step was generated by its own `solveElastic` call, without scaling displacement/reaction arrays. These are synthetic references, not measurements or general-geometry accuracy claims. The generator is `tests/fixtures/increment-ui-reference.mjs`; distribution files are `public/examples/increment-comparison-a.json` and `-b.json`.

The text field accepts only the wrapper `{"bundles":[{"spec":{},"steps":[]},...]}` with valid raw data inside. The file field accepts 2–4 individual `{spec,steps}` files. File selection alone does not render. Total input is limited to 2 MiB; each bundle also has the shared service's 1 MiB and other bounds. Duplicate curveIds, self-reported comparison tables/SVG and malformed inputs are refused.

Material, geometry and gauge differences remain attached to each curve. Curves are never connected to each other, and failed steps are never interpolated. CSV/JSON/SVG come from the same validated results. The current project, cases and displayed analysis result are unchanged. Editing input, selecting other files or failing validation clears previous previews and URLs; late async work cannot restore them.

Native details/buttons, labelled inputs and associated errors support keyboard use. Images shrink and links wrap at narrow widths; links use bright colors and underlines on the dark theme. Japanese/English switching does not change input or results.

This bounded comparison increment does not complete RESULTCURVE1, physical calibration or nonlinear hysteresis support.
