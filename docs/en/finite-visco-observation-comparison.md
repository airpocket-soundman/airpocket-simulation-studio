# Final synthetic finite-material-point observation comparison

[日本語](../finite-visco-observation-comparison.md) / [Input-history replay](finite-visco-input-history.md)

`compareFiniteViscoFinalObservation(historyRaw, observationRaw)` is a pure boundary disconnected from the product. It replays the existing history once from I/Z0 and compares **one final synthetic checkpoint only**. It adds no arbitrary-time interpolation, nearest-time matching, time shifts, observation series, state restore, structural solver, fitting or calibration. Existing reference/replay APIs and retention remain unchanged.

Both inputs are primitive UTF8 strings or ordinary Uint8Arrays: each at most1MiB, depth16,100000 values,1024-character strings and4096-entry arrays. Duplicate decoded keys, unknown fields, nonfinite exponents, unsafe huge numbers and malformed UTF8 are refused. Objects, Buffers/subclasses and shared backing buffers are refused. Both inputs are intrinsically copied before the first await, without invoking own buffer/byteLength accessors. ArrayBuffer brand checks reject shared-buffer prototype spoofing. Later mutations cannot split identity from computation; inputs remain unchanged on success/failure.

The observation has exact fields: schemaVersion1, kind `finite-visco-final-synthetic-observation`, model `synthetic-green-lagrange-maxwell-reference-v1`, fixed synthetic/provisional true and calibrated false; units `{time:'s',stress:'Pa',energyDensity:'J/m3-reference'}`; historyIdentity containing rawIdentity/canonicalIdentity; parameterRevision; exact final timeSeconds; origin `{kind:'synthetic-reference',description:nonempty text}`; values `{S:3x3,energyDensity,cumulativeDissipationDensity}`. Energy values are finite and nonnegative. S contains all nine second-Piola components, not engineering shear or Cauchy stress.

Both history hashes must exactly equal replay identities: even whitespace-only changes invalidate raw provenance. parameterRevision is independently recomputed as SHA-256 of the UTF8 canonical parameter-object JSON used by replay (sorted keys, no trailing newline). This differs from the original reference state's internal parameterRevision string. Claimed hashes are never trusted; hashes/descriptions are not signatures, authenticated provenance or calibration evidence. Time must exactly equal the accumulated replay time, without tolerance or interpolation.

Success returns completed true/status compared. Observed-minus-replayed stress components and maximum absolute component difference use Pa. Energy density and cumulative dissipation each have signed/absolute differences in J/m³-reference; no maximum mixes these with stress. There is no acceptance threshold, relative-error division, pass result or calibration decision. Fixed synthetic/provisional/uncalibrated flags remain. Neither full state nor observation series is returned.

Malformed raw data throws stable codes. Constitutive history rejection returns completed false/status history-rejected with the original failure code/stepIndex/completedSteps and no comparison. Identity/parameter/time mismatches use `FINITE_VISCO_COMPARISON_HISTORY_MISMATCH`, `PARAMETERS_MISMATCH` or `TIME_MISMATCH`. Failed stages are never interpolated into success.

Independent exact E-linear shear-ramp exponential formulas validate S12, energy and cumulative dissipation. Regressions cover known signed perturbations, exact identities/time/units, byte limits, late mutation, accessor nonexecution, shared-buffer spoofing, strict JSON and failed steps. See [evidence](../evidence/2026-10-24-finite-visco-observation-comparison.json). These are synthetic numerical comparisons, not measured materials, stress-free specimens, reaction forces, permanent plasticity, damage or necking. No solver/UI/MCP/project-persistence connection or FINITEVISCO1 completion is claimed.
