# CADから内部流体領域を取り出す

[English](en/internal-fluid.md)

「内部流路サンプル」は外径24・内径16・長さ60 mmの管壁をCADで作り、箱で両端を閉じ、内側の流体だけを取り出します。生成後は十分発達した層流に切り替わり、圧力差・粘度・密度を設定して計算できます。

## 自分のSTEPを使う

1. 閉じたCADの部品体積をSTEPで読み込む。
2. 「内部の流体空間を取り出す」を開き、流体の内側の点を指定。
3. 箱の最小位置・幅を指定し、開口を閉じるX/Y/Z端面をポートとして選ぶ。「モデルの範囲を箱に使う」は初期値を入れる補助です。CADの開口がその平面で閉じることを確認してください。
4. 「内部の流体領域を取り出す」。CAD差分の各体積から、指定点を含む一つだけを残します。ポートのボタンで端面全体を選択できます。
5. CADで確認できた円形・角形直管は層流計算へ自動で切り替え。その他の形状はメッシュ生成まで対応し、一般3D流れはまだ解けません。音響を選び、ポートや壁に音圧条件を設定することもできます。

閉じた空洞はポートを全て解除します。指定点が固体内・固体境界上にある場合、ポート以外の箱の面へ漏れる場合、宣言したポートが選択体積に接しない場合は拒否します。入口・出口は箱の軸に平行な平面に限定。任意方向の開口、曲面の蓋、複数CAD体積に分割された流体の結合は残作業です。

## 形状と計算

OCCのCAD差分を使い、流体を元の部品の単純な外接箱として代用しません。`gmsh.model.isInside` で指定点の所属を判定し、CADの境界面と体積を調べます。元のSTEP・管形状はプロジェクト内に保持。端面タグと選択点、CAD体積、除外した体積数をメッシュ結果に保存します。

直管の認識では対向する二つの端面、CAD面の種類、体積・面積を検査します。円管は円筒壁と円形端面、角管は軸に平行な平面壁と直方体体積が一致する場合だけ対象。解析メッシュの壁座標も照合します。流れは[十分発達した層流](analysis-guide.md)のスカラー速度モデルで、入口発達、曲がり、剥離、慣性・乱流を計算しません。Re ≤ 1500、Mach ≤ 0.1を確認。Gmshの一次四面体は曲面を平面化するため、CAD体積とメッシュ体積・流量には離散化誤差があります。

円管の検証例: 内半径8 mm・長さ60 mm、Δp=0.01 Pa、μ=0.001 Pa·s。解析のピーク速度は0.0026667 m/s、流量は2.6808e−7 m³/s。目標サイズ2 mmでは0.0027200 m/s、2.5737e−7 m³/s、端面流量差0.0191%。1.5 mmへ細分化すると流量誤差が減ります。角形STEP管もFourier級数の参照流量で検証しています。

## 共通API

`sourceModel` は `{kind:'fluidDomain', mode:'internal', solid:元のCAD, enclosure:[x,y,z,dx,dy,dz], seedPoint:[x,y,z], portPlanes:[...]} `。座標はmm。端面番号は0/1/2がX/Y/Z最小、3/4/5がX/Y/Z最大。組込みの管壁は `{kind:'tube', center:[x,y,z], axis:0|1|2, outerRadius, innerRadius, length}`。長さは中心の両側に半分ずつ広がります。

結果の `mesh.domainSelection` に `ports`、`cadVolumeMm3`、認識した `channel` を保存。ケース集の読込では端面・形状・元の設定の一致を検査します。UI経由とAPI経由で同じメッシュ・ソルバーを使います。

参照: [Gmsh公式API — isInside / OCC / getBoundary](https://gmsh.info/doc/texinfo/)。境界層メッシュ、任意の開口閉鎖、一般3D流体と共役熱伝達は別タスクです。
