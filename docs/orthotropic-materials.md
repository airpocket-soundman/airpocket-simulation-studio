# 直交異方性の材料基盤（PRINT2 実装中）

[English](en/orthotropic-materials.md)

構造の静的・微小ひずみ・線形CPU解析で、方向ごとの弾性定数と材料軸を使用できます。プロジェクトJSONまたはAPIの `materialProperties.orthotropic` に登録します。印刷条件から弾性定数を自動推定する機能は未実装です。3MF/G-codeの表示から解析形状への接続、壁・層・インフィルの詳細化、実測試験による校正も未完了です。

```json
{
  "model": "linear-orthotropic",
  "youngModuliPa": [1000000000, 2000000000, 3000000000],
  "poissonRatios": [0, 0, 0],
  "shearModuliPa": [400000000, 500000000, 600000000],
  "axes": [[1, 0, 0], [0, 1, 0], [0, 0, 1]],
  "source": "Synthetic analytical reference; not measured printing data",
  "testConditions": "Small-strain directional bar reference; zero Poisson ratios"
}
```

この例は架空の検証値です。材料の実測値として使用しないでください。ヤング率は E1/E2/E3、せん断弾性率は G12/G23/G31 の順で、単位はPaです。ポアソン比は ν12/ν23/ν31 の順です。νij は方向 i の単軸応力に対する −εj/εi と定義し、相反関係から逆方向の係数を計算します。出典の係数順と定義を確認して入力してください。

材料軸は材料方向1/2/3を全体座標で表した、互いに直交する単位ベクトルです。右手系を要求します。正定値でないコンプライアンス、数値的に不安定な係数、出典・試験条件の欠落を拒否します。

対応する方法は `pcg`、`pcg-strict`、`wasm-pcg` です。MFEM、WebGPU、固有振動、熱応力、超弾性、塑性、現在の等方的な疲労・破壊評価との組合せは拒否します。通常のヤング率・ポアソン比は異方性解析に使用しません。重力には別途、対象の見掛け密度が必要です。

結果へ定数・材料軸・出典・試験条件を保存します。ケース読込時は入力との一致に加え、変位からひずみと応力を再計算して検証します。一般材料の保存でも異方性の登録値を保持します。

検証は、方向別の棒変形、材料軸の入替え、形状・荷重・拘束・材料軸の同時回転、純せん断、等方極限、JavaScript/WASM一致、実際のWorker解析と保存・復元です。架空の数値参照によるエンジン検証であり、特定の造形品の実測検証ではありません。
