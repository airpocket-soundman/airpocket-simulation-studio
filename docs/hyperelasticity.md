# ゴムの有限ひずみ解析

[English](en/hyperelasticity.md)

「ゴム大変形サンプル」で試せます。材料物性の「圧縮性Neo-Hookeanモデル」を有効にし、せん断弾性率μと体積弾性率KをMPaで登録します。任意の試験曲線は伸長比と公称応力PaのJSON行列で記録します。自動フィットは行わず、材料に適した試験からパラメータを指定します。

この実装は圧縮性の対数体積エネルギーを使います。

$$W=\frac{\mu}{2}(\mathrm{tr}(F^T F)-3)-\mu\ln J+\frac{\lambda}{2}(\ln J)^2,\quad J=\det F,\quad\lambda=K-2\mu/3.$$

式の参照: [FEniCSの公式超弾性例](https://docs.fenicsproject.org/dolfinx/main/cpp/demos/demo_hyperelasticity.html)。計算はAirpocketの実装で、FEniCSソルバーの移植ではありません。

基準形状のTet4から変形勾配を計算し、第一Piola応力による内力と整合接線を組み立てます。荷重と指定変位を1〜30増分に分け、Newton法と残差を減らすバックトラックで釣り合いを解きます。反復上限は増分ごとに1〜50回、相対残差は1e-8。剛体運動が残る拘束、反転・潰れた要素、非正定値接線、未収束を拒否し、成功扱いの結果は返しません。局所座標の拘束と基準形状に作用する重力・一定方向の荷重に対応します。

結果の応力は現在配置のCauchy応力、ひずみはGreen-Lagrangeひずみです。せん断ひずみ成分は2Eij。変位はmm、応力はPaで保存し、画面ではMPaで表示します。増分ごとの残差、最小J、ポテンシャルエネルギーをケースに保存します。保存ケースの表示・復元にも対応します。

参照サンプルは10×10×40 mmの柱、μ=0.5 MPa、K=2 MPa。横変位を拘束し、上端に8 mmを指定します。F=diag(1,1,1.2)、最小J=1.2です。上端反力は第一Piola応力×元の面積、表示応力はCauchy応力と比較します。単軸の横方向自由なゴム試験とは拘束条件が異なります。

現時点の範囲はCPUのAirpocket JS/WASM、2000四面体・2000節点、K/μ=2/3〜20です。通常のほぼ非圧縮ゴムには混合要素などが必要で、このモデルでは拒否します。MFEM/WebGPU、適応再メッシュ、熱膨張、追従圧力、機械的接触、座屈の分岐追跡、粘弾性、破断は未対応です。モデルの限界を超える材料値を自動で変更しません。

API: 材料の `hyperelastic: {model:"neo-hookean-log", shearModulus:500000, bulkModulus:2000000, testCurve:[[0.8,-200000],[1,0],[1.2,200000]]}`。解析設定は `nonlinearLoadSteps` と `maxNewtonIterations`。圧力・熱応力や未対応実行方式の組み合わせはWorkerでも拒否します。

検証: エネルギーの数値微分と応力、応力の数値微分と整合接線、剛体回転、20%引張・圧縮の応力と反力、荷重指定と伸長比の独立解、試験曲線の保存、WASMの標準Worker経路とケース集の検証。
