# 振動モードから外部音響へ

[English](en/vibration-acoustics.md)

固有振動を計算し、ケースに保存します。解析分野を「音響」に切り替え、「音響領域と周波数」→「振動モードを音源にする」でケース・モード番号・最大振幅・位相を指定。「保存モードから外部音響を作る」で元の部品の周囲に球形の空気領域を作り、「解析を実行」します。音圧、位相、放射パワー、遠方界の指向性を表示し、連成入力と結果をケース保存できます。

## 一方向のモデル

現段階は**保存した直方体部品のモードを、指定振幅で振動させる一方向連成**です。固有モードだけでは応答振幅が決まらないため、最大振幅をユーザーが指定します。振動数は保存モードの固有振動数に固定。周波数に対する強制振動の応答や、音圧から構造へ戻る作用を計算していません。曲面、複数モード合成、減衰付き強制振動、双方向の流体付加作用は `COUPLE4B` の残作業です。

`exp(+iωt)` の約束で、複素変位 `u` から速度 `v=iωu`、空気領域の外向き法線をnとすると `∂p/∂n=-iωρ(v·n)`。弱形式の右辺は `∫(-iωv·n) Ni dS`。体積メッシュから法線の向きを判定し、部品表面では空気から部品へ向くことを確認します。表示面の頂点順は使いません。

独立した空気メッシュの界面節点で、保存した構造Tet4変位を四面体内補間します。平面界面なので節点は構造領域の表面にあり、外れた点を最近傍で代用しません。6面全ての面積を検査し、形状の変更、欠損界面、空気領域の内向き／外向き違いを拒否します。空気の各面上では移した節点値を線形に積分するため、構造と空気の非一致メッシュによる場の転送誤差は残ります。

位相と振幅は複素数として転送。正常速度による供給パワーは `-1/2 Re ∫p v_n* dS`。損失0・他の音源なしでは、放射境界で吸収されるパワーと一致することを検査します。有限の球面境界は1次近似で、一般振動場では境界半径による誤差を確認する必要があります。

## 制限・API

源の構造メッシュは最大2,000節点・8,000四面体。形状は未変更の単一の直方体。振幅は最短辺の1%以下、速度の上限目安はMach 0.1。圧力や吸音の手動境界を重ねないでください。過渡解析と周波数スイープは未対応です。周波数の損失係数と境界近似は既存の周波数音響に従います。

共通APIの `study.vibrationSource` に `name`、`modeIndex`（0から）、`mesh:{nodes,tetrahedra}`（mm）、`bounds:[x,y,z,dx,dy,dz]`（mm）、`displacement`（最大1 mmに正規化した全体座標のモード）、`frequencyHz`、`amplitudeMm`、`phaseDeg` を保存。`study.kind:'acoustic'`、`exteriorRadiation:true`、`frequency` は源と同じにします。結果の `coupling` に転送面数・面積・最大法線速度・振幅・位相、`velocityInputPowerW` に供給パワーを保存します。

自動テストは管内平面波の音圧・位相、反対面の法線と正味流量、位相180°での符号反転、JS/WASM一致、供給／放射パワー、欠損・変更形状拒否、実際に計算した構造モードからのWorker連成・保存復元を確認します。参照: [COMSOLのAcoustic–Structure Interactionモデル](https://doc.comsol.com/6.4/doc/com.comsol.help.models.sme.acoustic_structure/acoustic_structure.html)。本アプリでは記載された連成のうち構造→音の一方向だけを実装しています。
