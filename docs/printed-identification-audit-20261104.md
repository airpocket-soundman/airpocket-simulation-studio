# PRINTMEASURE3 同定監査（2026-11-04）

[English](en/printed-identification-audit-20261104.md)

指示101の合成曲線のみを対象とした修正。実測、校正、測定精度、材料自動適用の検証ではない。

- SLS保持ひずみに呼出側のmaxStrainを適用し、3未知数に対し少なくとも4保持点を要求する。
- 二直線の全入力履歴を単調性検査し、窓外での除荷を隠さない。負またはゼロ接線係数は本プロファイル外として拒否する（完全塑性の別モデルは追加していない）。
- 二乗探索は窓内512点まで。513点以上は探索前にidentified:falseとなり、間引きや折点候補の省略はしない。dataset全体の10000点上限は変更しない。
- 全同定係数の相対標準誤差と全成功診断の有限性を検査する。定応力曲線の未定義R²をJSON nullへ変換して成功扱いしない。
- optionsは通常/null prototypeの列挙可能なown data fieldsのみ。getterとsymbolや継承モデル名を拒否する。

標準誤差はモデル条件付き近似であり、校正精度・モデル正しさを保証しない。二直線の係数共分散は固定折点条件付き、降伏誤差のみ折点曲率を加える既存方式。多分岐/有限ひずみ/除荷/繰返し・完全塑性の同定は未対応。識別用datasetを独立検証済みとみなさず、既存importPrintedEquivalentDatasetsの試験片分離規則を変更しない。

証拠: [監査結果](evidence/2026-11-04-printmeasure3-audit.json)。進捗ファイルは変更していない。

入口接続時の追加確認では、極小の有限ひずみで係数の標準誤差が表現不能な場合と、SLSの極小時刻窓で任意診断値が非有限となる場合を再現した。拒否理由を維持し、表現不能な任意数値欄を省略する。Infinity/NaNをJSON nullへ変換して数値を得たようには扱わず、有限の拒否診断は保持する。[追加検証](evidence/2026-11-04-identification-refusal-finite.json)。
