# 実装する機能

[English](en/features.md)

以下はすべて計画。段階は roadmap.md を参照。

## 3D操作と領域指定

- STEPを主形式に、部品・アセンブリを読み込み。単位と寸法を確認。STLは補助入力とし、CAD面情報がないため選択・修復の制約を表示。
- マウスによる回転、パン、ズーム、標準視点、選択範囲へのフォーカス。
- 平面、円筒面、自由曲面の全体選択。複数面、部品、体積の選択。
- 表面上のブラシ、消しゴム、範囲追加・削除、取り消し・やり直し。
- 表面上の中心と半径、円筒の軸方向距離・角度などによる寸法指定。半径は表面に沿う距離か空間距離か明示。
- 囲み選択の見えている面だけ／奥まで選択を切り替え。初期設定は見えている面だけ。
- 半透明、部品非表示、断面、選択範囲の色表示と面積表示。
- 選択領域をCAD形状上の定義として保存し、再メッシュ後に再評価。節点番号だけには依存しない。
- 境界適合のためのCAD面分割、または明示したメッシュ近似を利用。表示領域と解析領域の面積差・境界誤差を表示し、許容値外は実行を止める。
- CAD更新で面参照が失われた場合は再選択を要求し、別の面へ黙って割り当てない。

## 構造

- 固定、方向別拘束、指定変位、合計力、圧力、重力。荷重矢印と拘束マーク。
- 全体座標、局所座標、曲面法線方向を区別。面荷重は合力・合モーメントを確認。
- 線形静解析、変位、反力、応力、ひずみ、材料に適した安全率。
- 後続: 大変形、塑性、超弾性、接触・摩擦、座屈、固有振動、疲労、損傷・破壊。
- 点荷重・固定端などの応力特異点を識別し、最大応力だけで破断を判定しない。

## 熱

- 定常・非定常熱伝導、指定温度、熱流束、合計発熱、体積発熱、対流境界、放射。
- 温度、熱流束、時間履歴、エネルギー収支。
- 後続: 接触熱抵抗、温度依存物性、温度分布からの熱膨張・熱応力。

## 流体

- 部品とは別に流体領域を作成。内部流路の抽出、外部流れの囲い領域、入口・出口の指定。
- 流速・流量・圧力境界、壁、対称面。まず非圧縮・単相・層流を対象。
- 速度、圧力、流線、圧力損失、流量と質量収支。
- 後続: 乱流、非定常、自然対流、固体と流体の共役熱伝達。圧縮性・多相流はさらに後段。

## 共通

振動・音響も対象とする。音源面・受音点・吸音境界を3D上で指定し、周波数応答、共鳴、音圧分布を表示する。詳細は acoustics.md。

- 材料ライブラリ、ユーザー物性、出典・単位・有効温度・試験条件。
- ソルバー選択、対応条件の事前確認、導入状況表示。
- メッシュ品質表示、局所細分化、メッシュ収束比較。
- 実行進捗、中止、ログ、失敗理由。未収束の結果を成功扱いしない。
- 結果のカラーマップ、凡例・単位、プローブ、断面、変形倍率、時系列。
- 解析ケース保存、複製、複数ソルバー比較、レポート出力。
- 計算時の形状・領域・物性・メッシュ・ソルバー版・設定・結果をまとめて保存。

### 円筒の角度・長さ指定
円筒軸・基準点・半径・半径許容差・軸方向の開始終了・開始角度と角度幅で表示三角形を選べます。角度は正の軸に対する右ねじ方向、0°はX（軸がXの場合はY）。端面は除外し、裏側も選択します。三角形中心による近似で、厳密な領域分割ではありません。最後に使った数値指定はプロジェクトに保存され、選択解除や保存復元後に再適用できます。UIはX/Y/Z軸、APIのstudioApi.selectCylindricalRegion(mesh,spec)は任意のaxis/referenceベクトルを使えます。specはorigin, axis, reference, radius, tolerance, axialMin, axialMax, startDegrees, sweepDegreesです。CAD更新時の面参照照合や厳密な再メッシュ適合（REG2/CAD2）は別の残作業です。

### 表示形状の不備検査
「表面を検査」で、部品ごとの開いた辺、非多様体辺、三角形の向き、重複、退化、接続成分、mm単位の寸法を確認します。同じ頂点を既定でmax(1e-8 mm, 寸法対角長×1e-7)以内で照合し、元データは変更しません。不備箇所は最大1000三角形を選択できますが、不備数は全件を集計します。1部品30万三角形が検査上限です。studioApi.inspectGeometry({toleranceMm})は同じ検査APIです。辺の閉鎖に合格しても自己交差、頂点の多様体性、正確なCADソリッドは未検査で、有効な解析形状を保証しません。単位は読込時の選択に従い、寸法表示で確認します。穴や重複は元のCAD/メッシュ編集ソフトで修正して再読込してください。自動修復はしません。「形状不備サンプル」で検査と不備の選択を試せます。

登録済み条件の「選択範囲で更新」で、荷重値・方向・材料などを保ったまま領域を置き換えられます。円筒の数値指定と完全に一致する選択で登録した条件には指定を保存し、「数値領域を再適用」で表示三角形から再選択・更新します。これは表示メッシュの分割変更に対応する近似選択で、CAD面の照合や厳密な境界分割ではありません。一致する三角形がなくなれば既存条件を変更しません。APIはreplaceConditionRegion(index)、reapplyConditionRegion(index)です。

### 断面・半透明・部品非表示
「内部を見る」でX/Y/Z方向の切断位置と残す側を設定し、元の形状と解析結果をクリップできます。新しい切断面は生成しません。露出した元の内部面を選択できます。半透明の手前の面は選択を遮るため、奥の面は部品非表示で選択します。部品非表示は条件設定モデルの表示操作で、解析対象は変更しません。表示設定はセッション内で使い、プロジェクトには保存しません。window.viewApi.get()/set({clipEnabled,axis,position,flip,opacity,hiddenParts})は同じ操作APIです。内部面選択サンプルは20 mmと8 mmの部品を重ねた表示専用モデルです。断面で内側64 mm²、半透明なら手前400 mm²、外側非表示なら内側64 mm²を実画面で検証しました。
