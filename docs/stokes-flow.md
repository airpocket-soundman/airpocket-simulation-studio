# 外部CAD周囲の低Reynolds数Stokes流

[English](en/stokes-flow.md)

v0.37でCPUの速度・圧力連成、共通API、Worker、測定、保存結果の整合検査を実装。209テスト、公開配信物21項目、公開画面22項目が成功しました。以下は限定試作の対応範囲と個別試験値で、任意形状の精度保証を示すものではありません。

対象は、有限の外箱内に置いた固定CAD固体の周囲を流れる、定常・非圧縮・Newton流体の3D低速粘性流です。外箱の全境界に同じ速度ベクトルを指定し、固体表面は速度ゼロのno-slipとします。圧力の加算定数は1節点の基準値で固定します。流路専用の十分発達した層流モデルとは別の速度・圧力連成問題です。

## 物性と範囲

動粘性係数ではなく粘度μ（Pa·s）、密度ρ（kg/m³）、外側速度U（m/s）と代表長さL（m）を使用します。寸法入力がmmの場合はReynolds数の計算でmへ換算します。対象流体の温度・組成に対応する測定値や信頼できる物性出典を入力してください。材料名だけから物性や抗力の保証値を決めません。

`Re=ρ|U|L/μ ≤ 0.1`を試作の適用上限とします。代表長さLは固体の代表径とし、球なら直径2aです。定義と入力値を結果に記録し、メッシュ寸法を代表長さの代わりに使わないでください。この上限は粘性支配を選別する条件であり、任意形状の誤差上限ではありません。慣性項、乱流、非定常流、圧縮性、非Newton性、流体構造の双方向連成は対象外です。実装上限はCPU GMRES、2000節点・8000四面体で、MFEM/WebGPUや適応再メッシュの対応を意味しません。

## 数値モデルの検証点

物理圧力を使うStokes方程式は`−div(2μ ε(u))+grad(p)=0`、`div(u)=0`、`ε(u)=(grad(u)+grad(u)ᵀ)/2`です。対応する混合弱形式は粘性項・圧力と速度発散の結合・非圧縮条件を含みます。参照実装には圧力符号を反転した規約もあるため、式と圧力表示・表面応力の符号を合わせて確認します。

速度と圧力を同次数の線形Tet4で近似する場合、圧力の安定化が必要です。PSPGは運動量残差を圧力試験関数の勾配で評価する安定化で、係数・長さ尺度・符号を検証対象とします。安定化した離散式の収束だけでは、要素ごとの発散や流量収支の精度を保証できません。

固体に作用する力は圧力と粘性を含む全応力`σ=−pI+2μ ε(u)`に基づきます。流体領域の内向き境界と固体の外向き法線は逆向きです。表面積分による力と離散反力を同一量と仮定せず、使用する算出法・符号とメッシュ収束を確認します。

実装では表面積分を`dragN`、固定壁の速度方程式の離散残差を反転して得る反力を`reactionDragN`と区別します。低次要素の表面勾配による抗力は精度が低くなる場合があり、参照比較では弱形式と整合した反力も確認します。

## 有限外箱と受入条件

画面の一様外側速度は有限外箱の境界条件です。外箱の寸法や固体との距離が流れと抗力に影響するため、無限領域の球の抗力`6πμa|U|`と完全一致する条件ではありません。メッシュ比較と外箱拡大の比較を分けて記録してください。

球の無限領域解を検証する場合だけ、試験コードでその解析解の速度を有限外境界に指定し、半径aの球に対する`6πμa|U|`と比較します。これは画面の一様速度境界の精度証明には使えません。受入検証では、独立参照解、μ/Uの線形比例、流向反転、圧力基準の変更、境界速度、発散・境界流量収支、外箱・メッシュ依存性、未収束と上限超過の拒否を確認します。保存復元やWorker/UI検証は追加の統合検証です。

一次資料: [DOLFINx公式のStokes混合弱形式と圧力符号の注記](https://docs.fenicsproject.org/dolfinx/main/python/demos/demo_stokes.html)、[INL OpenPronghorn公式の同次数要素とPSPG](https://openpronghorn.inl.gov/modules/navier_stokes/cgfe.html)、[COMSOL公式のcreeping flowの前提](https://doc.comsol.com/6.4/doc/com.comsol.help.corr/corr_ug_fluidflow.09.003.html)、[有限境界がStokes抵抗に与える影響の原著論文](https://www.cambridge.org/core/journals/journal-of-fluid-mechanics/article/abs/effect-of-finite-boundaries-on-the-stokes-resistance-of-an-arbitrary-particle-part-3-translation-and-rotation/F8D5C0143118CD053A673C9C2DA8BDFA)。これらのソルバーを移植したものではありません。

開発中の数値試験記録: 半径5 mmの球、μ=1 Pa·s、ρ=1000 kg/m³、U=0.001 m/sの解析外境界試験では、局所細分化後の離散反力による抗力誤差は約6.25%（粗いメッシュでは約16%）、表面積分抗力は約28.3%、節点圧力の相対誤差は約27.7%でした。これらは試作の精度限界を示す個別試験値で、固定済みの最終受入結果や一様外箱UIの保証値ではありません。

共通APIの設定は`study.kind:'creepingFlow'`、`dynamicViscosity`、`fluidDensity`、`freeStreamVelocity:[ux,uy,uz]`です。任意の`referenceLengthMm`を省略すると元CAD固体の最大包絡寸法を使い、指定する場合もその寸法を下回る値は拒否します。外部`fluidDomain`と直方体の`enclosure`が必要で、手動の境界条件は登録しません。`stokesBoundary(mesh,source,study)`は外箱速度、固体no-slip、圧力基準と有効代表長さを生成します。STEPでは元CAD包絡寸法の記録が必要です。

v0.40では「速度要素」から従来の安定化P1/P1とTaylor–Hood P2/P1を選択できます。`study.stokesVelocityElement:'P2'`で二次速度・一次圧力を使い、省略時は従来のP1です。P2は圧力安定化を使わず、速度の辺中間節点を別に保持します。形状は従来の直線四面体・平面三角形境界のままで、曲線CADへの二次幾何適合ではありません。

P2の点測定は10節点の二次形状関数、圧力は4頂点の一次形状関数を使います。断面は各三角形を4分割し、中間位置にも二次速度を評価して描画します。画面の「節点最大流速」は頂点と辺中間節点の最大値です。速度色の上限には、要素内の節点間極値も包含する二次Bernstein係数の速度上界を表示します。Reの拒否にもその上界を使います。応力と発散のセル値は重心での値、発散RMSは四点積分です。

P2の上限は元の2000頂点・8000四面体に加え、速度節点12000と自由度40000です。CPUのJS/WASM GMRESを使用し、GPU・MFEM・一般慣性流・乱流は未対応です。保存復元では中間節点座標・接続・境界速度・圧力基準・速度上界・応力・発散・反力・流量を再評価し、内部の運動量式と弱い非圧縮条件も照合します。元のP1保存ファイルは変更なしで読み込めます。

細分化した解析外境界の球試験では反力抗力誤差1.77%、表面積分抗力8.20%、節点圧力9.81%でした。一様速度の有限外箱UIとは境界条件が異なり、その精度保証値ではありません。メッシュと外箱寸法を変えた比較は引き続き必要です。

## Stokes GMRESの構造化反復残差

P1/P2 Stokesは`stage:"iteration",solver:"stokes-gmres"`、velocityElement、iteration/residual/tolerance/convergedとphase/residualKindを返します。残差は全て無次元で、途中の速度・圧力場配列は提供しません。既存のjobEvents経路を使い、中間値は常にprovisionalです。

restart-check/preconditioned-relativeはGMRES外側ループの先頭（初期iteration0を含む）で測定する、平衡化・左ILU0前処理された縮約系の相対残差。arnoldi-estimate/preconditioned-relative-estimateは同じ系のArnoldi推定で、最初のinner iteration・10反復ごと・許容差/happy break/上限/再開区切り直前に重複なく通知します。推定値を元の運動量式残差と読み替えないでください。

final-check/true-relativeは既存の元の無次元full systemの自由方程式残差をrawRhsノルムで正規化した数値検査が1e-8を満たした後の通知です。zero RHSでGMRESを省略してもiteration0のfinal-checkはあります。各convergedはその残差条件のみを示し、後続のregime検査等で失敗することがあります。ジョブ終端の成功、流量収支・メッシュ独立性・実物精度を保証しません。
