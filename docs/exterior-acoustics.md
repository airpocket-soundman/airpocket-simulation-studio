# 外部放射と遠方界の指向性

[English](en/exterior-acoustics.md)

「球音源・外部放射サンプル」で試せます。一般のSTEPや内蔵部品は「周囲の球形音響領域を作る」で包み、断面表示で音源面を選んで音圧を登録します。球の半径は表示形状の外接範囲と余白から決定し、実際のCAD境界を含むことをメッシャーで検査します。元の部品を球からOCCで差し引いて空気領域を生成します。密閉された部品内の空洞は外部領域から除外します。

外側の球には1次の球面放射条件を自動設定します。時間の約束は exp(+iωt)、外向き波は exp(−ikr)/r。バルク損失を含む波数は k_c²=k²(1−iη) です。境界条件は ∂p/∂n=−(ik_c+1/R)p で、弱形式に (ik_c+1/R)/ρ の境界質量を加えます。外周への音圧・別のインピーダンスの重複、閉じていない球面を拒否します。

理論の参考: [球面放射境界](https://doc.comsol.com/6.4/doc/com.comsol.help.comsol/comsol_ref_acoustics.27.20.html)。これはAirpocketの1次近似で、COMSOLの高次境界条件やソルバーの移植ではありません。PML、BEM、厳密な全モードの無反射境界は未対応です。

遠方界は外周球面の音圧と法線微分からKirchhoff–Helmholtz積分の遠方界近似を計算します。閉曲面上の p と q=∂p/∂n に対して、方向dの振幅を F(d)=1/(4π) ∫[ik_c(n·d)p−q]exp(ik_c d·y)dS で評価し、exp(−ik_c r)/rを掛けて指定距離へ換算します。yは球中心からの位置です。境界三角形には7点積分を使います。指定距離が近接領域にある場合も、表示値は遠方界の換算値で、実際の近接音圧ではありません。領域内の音圧は3Dの測定機能で別に確認します。[外部場積分の理論](https://doc.comsol.com/6.4/doc/com.comsol.help.aco/aco_ug_pressure.05.172.html)

XY、YZ、ZXの測定面、12〜180方向、換算距離を設定できます。角度は選択した正の軸まわりの右ねじ方向です。表示はピーク音圧mPa、RMS基準のSPL、最大音圧を0 dBとする相対値。極座標図は0〜−60 dBです。音圧0では相対指向性を定義しません。保存ケースにも放射パワー、方向別の複素音圧、グラフ用データを保存します。

球音源は半径5 mm、境界音圧1 Pa、外周20 mm、1000 Hz、空気密度1.2 kg/m³、音速343 m/s、損失0です。参照解 p(r)=a/r exp[−ik(r−a)] より1 m換算5 mPa、放射パワー2πa²/(ρc)=3.8163e−7 W。4 mmメッシュの誤差約6.3%から2 mmで約2.5%へ減少し、画面でも5.1248 mPaを確認しました。領域半径20/30 mm、座標移動、振幅2倍/パワー4倍、l=1角度成分の指向性も検証しています。

メッシュの目標サイズに加え、実際の最長辺が波長の1/6以内かを確認します。一般形状の放射では有限境界の近似誤差が残るため、領域サイズとメッシュを変更して比較します。現時点では構造振動からの自動励振、非一様媒質、粘性・熱境界層、過渡音と試聴は別タスクです。

再メッシュで曲面全体の条件を保つため、Gmsh由来の表示面には元のCAD/形状パラメータのSHA-256とCAD面タグを保存します。同じ形状の同じ面全体ならタグで対応し、表示メッシュの粗さに基づく幾何検査も行います。形状データが変わった場合は再選択を要求します。一般の部分領域は引き続き三角形への投影近似で、正確な寸法パッチはREG2の残作業です。

検証: tests/acoustic-radiation.test.mjs、tests/source-identity.test.mjs、tests/worker-pipeline.test.mjs。`npm run test:published` も配信版の外部音響をチェックします。
