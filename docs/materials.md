# 材料モデル

[English](en/materials.md)

材料名だけで精度は決まらない。材料カテゴリ、構成則、物性データ、破壊判定を分離する。数値未入力のテンプレートは計算不可とし、仮の物性を実物のデータとして表示しない。

|カテゴリ|初期の扱い|高度な扱い・必要データ|評価|
|---|---|---|---|
|金属|線形弾性。E、ポアソン比、密度、降伏強度|応力ひずみ曲線、塑性、温度依存、疲労|延性金属の降伏に対するvon Mises評価など|
|樹脂|条件を限定した線形弾性|温度・速度依存、粘弾性、クリープ、塑性、成形・積層異方性|材料と試験条件に合う強度基準|
|ガラス|線形弾性による変形・主応力|欠陥・表面状態、破壊靱性、必要なら統計的強度|最大引張主応力等。金属の降伏判定を適用しない|
|ゴム|カテゴリ登録は初期。実用的な大変形解析は後段|超弾性パラメータ、圧縮性、引張・圧縮等の試験曲線、必要なら粘弾性|適切な要素と大変形解析。硬度だけから破断を予測しない|
|流体|単相ニュートン流体|密度、粘度、温度依存、乱流モデル用条件|質量収支・圧力損失等|

熱には熱伝導率、比熱、密度、熱膨張係数、必要に応じ放射率を登録。熱応力では基準温度も必要。

保存項目: データ出典、グレード、単位、有効温度、ひずみ速度、方向性、試験条件、校正履歴。ガラス・樹脂・ゴムの破断荷重は、材料名や単一の引張強度だけから保証しない。解析モデルと実験で検証した範囲を明示する。
