# 閉鎖STLの体積メッシュ

[English](en/stl-meshing.md)

初期対応の対象は、外向きの三角形で構成された単一の閉鎖した凸shellです。最大2000三角形で、STL読込時の単位指定を反映したmm座標を保存します。STLは平面三角形の近似形状であり、元のCAD曲面を復元するものではありません。

APIの形状ソースは`{kind:'stl', positions:[x0,y0,z0,x1,y1,z1,x2,y2,z2,...]}`です。`positions`は三角形ごとの頂点を並べた有限数の配列で、単位はmmです。他のキーは受け付けません。プロジェクトの表示メッシュと解析用ソースを同じ正規化座標で保存し、復元時に単位を二重適用しないでください。

検査では近接頂点を許容差で照合し、穴、非多様体辺、重複、退化、面の向きの不一致、複数shellを拒否します。全体が内向きの場合も符号付き体積で拒否します。各面の外向き法線について全頂点が内側の半空間にあることを確認し、凹形状を拒否します。許容差は形状寸法に依存し、極薄・数値的に不安定な形状も対象外です。自動修復は行いません。

この凸形状の制約は任意STLの自己交差検出器ではありません。`selfIntersectionsChecked:false`は一般的な三角形交差検査をしていないことを表し、`convexBoundaryChecked:true`は支持半空間の検査に合格したことを表します。空洞、複数部品、凹部を持つ形状にはSTEPなど対応する形状形式を使ってください。

Gmshの離散表面からの体積メッシュの背景は[公式チュートリアルt13](https://gmsh.info/doc/texinfo/gmsh.html#t13)を参照してください。利用可能な解析方式・要素数上限は各ソルバーの制限にも従います。立方体の体積や単軸解との照合は任意形状の精度保証ではなく、独立参照解とメッシュ比較が必要です。
