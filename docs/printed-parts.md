# 3Dプリント部品モード（最終段階の任意機能）

[English](en/printed-parts.md)

関連企画: [自作可能・販売する試験機とBambu用試験片でCAEパラメータを取得する](printed-material-measurement.md)。利用者自身が測定する仕組みを提供し、我々が定数を測定して公開する活動とは分ける。

標準の解析機能が成立した後に着手する。Bambu Studioのプロジェクト3MF、スライス済みの.gcode.3mf、G-codeを区別し、ファイル内容とバージョンを確認する。モデル形状や必要な設定が含まれないファイルは、不足を表示して補助データを求める。

積層方向、層高さ、壁数、インフィル率・パターン、材料、押出経路を可能な範囲で読み込む。最初は校正した異方性の等価材料モデル、後段で壁・インフィル・層間を明示したモデルを検討する。等価モデルと詳細モデルの違いを表示する。

スライスデータだけでは層間接着・空隙・造形不良・破壊強度は確定しない。フィラメント、温度、造形条件に合わせた試験データを登録し、積層方向別の試験片や実部品の結果で検証する。プリンターへの送信・造形操作はこの機能の範囲に含めない。

公式資料: [Bambu Studio](https://github.com/bambulab/BambuStudio)、[CLIの3MF出力](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage)。現在は計画段階。
