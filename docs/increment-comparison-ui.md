# 複数の段階グラフを比較

[English](en/increment-comparison-ui.md) / [単一曲線UI](increment-curve-ui.md) / [共通曲線出力](increment-curve-export.md)

「複数の段階グラフを比較」で2〜4件の生bundleを検証し、共通の静止SVG内に荷重–標点伸び（mm・N）と工学SS（ひずみ1・応力Pa）の2図を表示する。色と凡例で系列を区別する。真応力・塑性/粘弾性の状態履歴ではなく、独立した線形弾性結果の比較である。

最初は「参照Aを保存」「参照Bを保存」で同梱JSONを保存し、ファイル欄で2件を同時選択して「検証して比較グラフを表示」を押す。AはE=1e9Pa・0/10N・失敗15N・20N、BはE=2e9Pa・0/20N・失敗30N・40Nの単一Tet4。各成功段階はそれぞれ `solveElastic` で解いて生成し、変位・反力をスケーリングしていない。実測や一般形状の解析精度を保証する資料ではない。生成元は `tests/fixtures/increment-ui-reference.mjs`、配布ファイルは `public/examples/increment-comparison-a.json` と `-b.json`。

テキスト欄は `{"bundles":[{"spec":{},"steps":[]},...]}` の専用wrapper形式を使う（中身は有効な元データが必要）。ファイル欄は個々の `{spec,steps}` を2〜4件選択する。ファイル選択だけでは描画しない。合計最大2MiB、各bundleは共有サービスの最大1MiBなどの制限を受ける。重複curveId、自己申告の比較表やSVG、壊れた入力を拒否する。

各曲線の材料・形状・標点の違いは保持して比較する。別曲線同士をつないだり、失敗段階を補間したりしない。CSV/JSON/SVGは同じ検証済み結果から生成し、保存リンクで取得する。既存project・ケース・表示中の解析結果を読み替え/変更しない。入力変更、ファイル再選択、検証失敗で旧表示とURLを破棄し、遅れて完了した処理も再表示させない。

サイドバーの図が小さいときは、検証成功後の「グラフを大きく開く」で同じSVGを別タブへ開ける。保存操作とは別の通常リンクで、再生成しない。入力変更・失敗・破棄時にこのリンクも無効化し、古いBlob URLを解放する。

標準details・button・label付き入力とエラー先でキーボード操作に対応し、狭幅では画像を縮小してリンクを折り返す。リンクは暗い背景に合わせて明色と下線を使う。日本語/英語切替は入力や結果を変更しない。

比較機能の限定成果であり、RESULTCURVE1全体、物理校正や非線形ヒステリシスの完了を意味しない。
