# 振動・音響

[English](en/acoustics.md)

すべて計画段階。構造物の振動、空気等を伝わる音、流れが生む音を区別する。

## 実装する機能

- 部品の固有振動数とモード形状、加振力による周波数応答、減衰の設定。
- 音響領域の作成、音源面の選択、音圧または法線速度などの加振条件、受音点の配置。
- 空洞・管・筐体などの共鳴、周波数掃引、音圧分布、位相、受音点の応答曲線。
- 剛壁、インピーダンス・吸音境界。材料の吸音は周波数依存データを入力し、材質名だけで決めない。
- 音速、密度、減衰、必要な温度条件を登録。固体には動的物性・減衰を設定。
- 音圧レベルは基準音圧、実効値／ピーク、周波数、必要なら重み付けを明示。空気と水の基準を混同しない。
- 後続: 板・筐体の振動からの音の放射、構造音響連成、指向性、遮音・透過損失。
- 外部音響は開放境界の近似と領域サイズの収束を検証。専用BEM等は必要が生じた段階で追加調査。
- さらに後続: 流体騒音、過渡波動、インパルス応答と可聴化。単一周波数の音圧結果から実際の音色を生成したとは扱わない。

## ソルバーと検証

最初はElmerのHelmholtzモデルで、線形・周波数領域の音響を対象にする。Code_Asterは追加候補。構造振動のCalculiX等との受け渡しは、複素振幅、位相、周波数、法線速度を保存し、対応を検証する。

矩形空洞の共鳴周波数、管の境界条件別の共鳴、既知の波動解で検証する。最高対象周波数の波長に応じたメッシュと、周波数掃引の間隔を設定し、共鳴ピークを取り逃がさない。無減衰モデルの過大なピークを現物の音圧として提示しない。

公式資料: [Elmer Models Manual / Helmholtz Model](https://www.nic.funet.fi/pub/sci/physics/elmer/doc/ElmerModelsManual.pdf)、[Elmer公式リポジトリ](https://github.com/ElmerCSC/elmerfem)、[Code_Aster概要](https://code-aster.org/en/product/main)。
