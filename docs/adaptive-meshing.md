# 適応メッシュと再解析

[English](en/adaptive-meshing.md)

解析用の体積メッシュ生成を実装する。表示用三角形の細分化だけでは解析機能の完了としない。

ループ: 初期メッシュ → 解析 → 誤差・変位・ひずみ・応力の評価 → 局所細分化 → 境界条件の再転送 → 再解析 → 収束判定。

ユーザーが希望する変形量の大きい領域を細分化対象にできるようにする。ただし変位の絶対量だけでは剛体移動や滑らかな曲げを過剰に細分化するため、変位勾配、ひずみ・応力勾配、残差または回復法による誤差指標も使う。指定領域、接触、薄肉部にも局所サイズを設定する。

停止条件は評価量の相対変化、推定誤差、最大反復数、最大要素数、メモリ・時間上限。特異点で応力が収束しない場合はその理由を表示して止める。反復ごとのメッシュ、入力、結果、収束曲線を保持する。材料・荷重を黙って変更しない。

初期は細分化のみ。粗密の最適化・要素の粗化は保存則と領域境界が維持できることを確認してから追加する。結果を使うループの完成はソルバーの接続後。現在は計画段階。
