# 適応メッシュと再解析

[English](en/adaptive-meshing.md)

Gmshの体積メッシュ → 構造解析 → 応力回復・ひずみ・変位の指標 → 局所細分化 → 境界条件の再転送 → 再解析を最大5回行います。全反復のメッシュ・境界・結果を保存します。入力材料・荷重は変えません。

変位と最大von Mises応力の両方について、細分化された3解像度以上の直近2変化を比較します。既定の変化許容値は変位1%、応力5%。両者が満たされ、回復応力の変動指標が0.2未満の場合に停止します。これは評価量の安定判定で、厳密な誤差保証ではありません。

変位が安定し、ピーク要素の体積の立方根が2回続けて5%以上減少し、応力が許容値を超えて増加し、その増加率が減衰していない場合に「応力特異点の疑い」で停止します。応力集中と特異点の数学的な確定には追加の形状・境界・局所収束検査が必要です。高応力の場所が移る場合も、ピーク要素サイズだけでは十分に判断できません。

要素数上限・処理間での時間上限・メッシュ停滞では収束未確認として、最後に完了した解析を返します。初回解析が上限を超えた場合はエラーです。時間上限はメッシュ生成や解法の途中を即時中断する保証ではなく、別にワーカーの120秒上限と中止ボタンがあります。

画面に要素数・最大変位・最大応力・ピーク要素サイズ・経過時間を表示します。APIの `maxAdaptiveElements` / `maxAdaptiveSeconds` / `tolerance` / `stressTolerance` でも設定でき、解析ケースに保存します。粗化・接触の構造解析・認証された誤差評価は未対応です。

参考: [COMSOLのメッシュ収束の解説](https://www.comsol.com/support/knowledgebase/1261.)。局所の応力と変位は別々に収束を確認する必要があります。本アプリの閾値は実装上の診断設定です。
