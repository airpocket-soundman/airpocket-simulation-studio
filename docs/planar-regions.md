# 平面の矩形領域を寸法で指定

[English](en/planar-regions.md)

単一のSTEPまたは直方体の外側平面に、矩形領域を指定できます。「平面を矩形寸法で選ぶ」で面に垂直な軸、面の位置、残り2軸の上下限（mm）を入力します。残り2軸はX/Y/Zの順です。Z=40の面でX=2〜8、Y=2〜8なら、面積は36 mm²です。

「矩形領域を選択」を押し、固定・荷重・熱・音などの条件を追加します。黄色の矩形が指定範囲です。元の表示三角形は範囲と交差するものを記録しますが、計算ではその三角形全体を使いません。矩形の輪郭で実際のCAD面を分割し、メッシュの辺を境界に合わせます。分割前のCAD面番号との対応を保持するので、他の面全体の条件も残ります。

矩形は1枚の外側CAD平面に全て入る必要があります。最大20領域。座標を回転すると斜め平面にも対応します。曲面・複数部品・接触熱抵抗への矩形指定は未対応です。再メッシュ時に寸法を再適用し、CAD面積とメッシュ面積を検証します。合計荷重は指定値を保ちますが、拘束・応力の精度には別途メッシュ収束の確認が必要です。

共通APIでも指定できます。

```js
studioApi.selectPlanarRegion(0, {axis: 2, position: 40, min: [2, 2], max: [8, 8]});
studioApi.addCondition({type: 'force', value: 100, direction: [0, 0, 1]});
```

プロジェクトとケースには寸法を保存します。読み込み時には表示面への適合、保存済みメッシュの範囲・面積を検査し、矛盾したデータを拒否します。通常の面・ブラシ選択に切り替えると寸法指定を解除します。

実装は[GmshのOpenCASCADE BooleanFragments](https://gmsh.info/doc/texinfo/gmsh.html#gmsh_002fmodel_002focc_002ffragment)を使用します。検証は `tests/planar-region.test.mjs` と `tests/worker-pipeline.test.mjs`。56 mm²のCAD領域・異なるメッシュサイズでの100 N荷重保存、X/Y/Z各面のSTEP分割、36 mm²荷重の反力釣り合い、保存復元と破損データ拒否を確認します。
