# 印刷材料パラメータの読取専用同定

[English](en/printed-identification-ui.md) · [測定JSON検査](printed-measurement-ui.md) · [同定の監査と限界](printed-identification-audit-20261104.md)

材料設定の後にある「印刷材料の測定JSONを検査」を開き、JSONを入力します。既存の検査・試験片選択・応力ひずみ表示・保存に加え、その下の「小ひずみパラメータを同定」を利用できます。材料・プロジェクト・ケース・解析入力には書き込みません。同定結果の自動適用や新しい解析を行いません。

モデルと必須条件は空欄から利用者が入力します。最大工学ひずみ、最小点数、許容相対標準誤差は全モデルで必須です。二直線には接線/弾性係数比の上限（0より大きく1未満）、SLSには保持ひずみの相対許容差も必要です。未入力・不正値は実行を拒否します。表示される係数はPa、緩和時間はsです。試験片ごとの拒否理由も表示し、同定不能を成功した材料と扱いません。

線形は原点通過、二直線は単調載荷・正接線・窓内512点以下、SLSは一分岐の保持緩和です。SLSには少なくとも4保持点を要求します。標準誤差はモデル条件付きの近似で、測定精度ではありません。合成/実測申告を区別し、どちらも未校正・精度未検証・材料未適用と表示します。実測曲線の同定精度は今回検証していません。

最大2 MB・100試験片・総10000点の既存parserと同定APIをそのまま使います。専用module workerを1要求ごとに作り、処理開始後10秒で打切り、編集・取消・クリア・画面破棄・BFcache退避でも終了します。結果は原文SHA-256、条件、世代に結び付け、旧結果は即消去します。返信は100試験片・モデル別最大3係数・256 KiB以内、密な配列・有限数・未校正フラグ・単位付き表示を検査します。入力SHAの準備はキャンセルで中断できないため、実digestが終わるまで1枠を保持し、新たな処理を開始しません。取消による安全な解放を偽装しません。

Ctrl/⌘+Enterは条件欄から同定を実行します。日本語/英語切替は入力・条件・原文を変更しません。新しい保存リンクや材料適用ボタンは追加していません。実機表示の確認は統合後に別途行います。

[実装検証の証拠](evidence/2026-11-04-printed-identification-ui.json)


親の測定JSON検査と同定は、それぞれSHA準備の1枠を実完了まで保持します。返信が有限でも、接線比、正で窓内の降伏/保持ひずみ、降伏応力＝弾性係数×降伏ひずみ、R²が1以下というモデル整合がなければ拒否します。測定精度を証明する検査ではありません。


3種類の「合成例と条件を入力」ボタンは、架空の曲線と表示される確認用条件を入力するだけで、自動同定しません。読込時は上のJSONを置換し、旧検査結果・保存リンクを無効にして旧同定を取り消します。条件クリアは原文を変更しません。例は実測でも材料推奨値でもなく、既存の測定検査用合成例は変更していません。[数式・真値・原文の固定hash](evidence/2026-11-04-printed-identification-examples.json)。
