# 結果ビューアと出力の製品仕様案

[English](en/result-viewer-direction.md) / [複数ケース同期表示の設計メモ](view-compare-design.md)

策定日: 2026-10-14。直感的に結果を理解し、設計判断に使い、他者へ伝えられるビューアを差別化の柱とする。以下は目標仕様であり、未対応の解析を表示機能によって対応済みとは扱わない。

## 現状

独立した線形弾性の段階結果bundleを検証し、静止グラフとCSV/JSON/SVGを生成する限定UIは[段階データの静止グラフ](increment-curve-ui.md)を参照。塑性履歴・解析からの段階自動生成ではない。

表面結果、表面メッシュ、内部メッシュ、断面、点測定、PNGとWebM、固定フレームの連番PNG（STORE ZIP＋manifest.json、実時間非依存）、回転・変形往復・保存過渡音響フレーム・移動断面のアニメーションがある。単一ビューは[回転GIF](single-orbit-gif.md)に対応し、時間/変形/断面GIF、MP4、流線と粒子アニメーションは未対応。比較GIFは回転/時間/表示倍率に対応。[既存の出力仕様](visual-export.md)と[断面仕様](result-sections.md)を参照する。

## 表示レイヤー

| レイヤー | 操作と目的 |
|---|---|
| 元形状と部品 | 表示・非表示、部品別透過度、色。内部結果と外形を同時に理解する |
| 結果ヒートマップ | 物理量・成分・単位、カラーマップ、範囲、透過度を選ぶ |
| ワイヤーフレーム | 表面・内部メッシュを別々に切り替え、線色と透過度を調整 |
| 変形形状 | 元形状を重ね、倍率・実寸表示を選ぶ。倍率を常に明示 |
| 断面 | 任意平面、位置・向き、複数断面、平面移動アニメーション |
| ベクトル矢印 | 速度・変位・熱流束等。密度、長さ倍率、正規化、色を設定 |
| 等高線と等値面 | 断面等高線と3D等値面を区別し、値・本数・透過度を指定 |
| 流線と粒子 | シード位置と密度、速度による色付け、軌跡表示 |
| 注記と測定 | 点測定、極値、凡例、時間、荷重と拘束、設計版を表示 |

各レイヤーを独立して操作できる構成とする。初期画面は物理分野ごとのプリセットと主要操作に絞り、詳細設定で調整する。透過表示では深度順と遮蔽を確認し、必要なら断面を併用する。

## 時間と流体の表現

保存された時間履歴に対して再生・停止・コマ送り、時刻入力、時間範囲、速度、ループ、測定点の履歴グラフを提供する。色範囲は時間範囲全体で固定する方式を基本とし、フレームごとの自動範囲を使う場合は明示する。複数ケースの比較では共通の色範囲を使えるようにする。

流体は速度の色面、間引いた矢印、流線、流れる粒子、圧力の断面等高線・色面・等値面を組み合わせる。全要素への矢印配置は選択肢とし、初期状態は混雑を避ける間引き表示にする。シードを入口面、点、線、領域から指定できる案とする。

定常場の流線上で粒子を動かす表示は「定常速度場による可視化」と示す。非定常の粒子軌跡は保存時系列の速度場を時間積分する必要があり、両者を区別する。表示補間は計算済み時刻・解像度を増やしたことにはならない。粒子の速度と動画の再生速度を区別し、壁・領域外・停滞部の終了条件を設ける。

静解析の変形往復と固有モードの振動表示は実際の動的応答ではない。動的構造解析のアニメーションは実時間履歴が計算・保存された場合に提供する。利用可能な表現は結果の種類に基づいてAPIから取得する。

## カメラとアニメーション書き出し

利用者が3Dを回転して選んだ角度を保存し、固定カメラ、回転、カメラキーフレームを選ぶ。選択した物理時間範囲、再生時間、FPS、解像度、背景、凡例・時刻・注記、表示レイヤーを指定して出力する。

- PNGは静止画、WebM/MP4は動画、GIFは短いプレビュー用途とする。
- MP4のブラウザ直接出力はコーデック・エンコーダ対応を検出する。未対応時はWebM、連番PNG、任意のネイティブ変換経路を提示する。
- GIFエンコーダ等は必要時に取得する。色数・サイズ・メモリ制限を表示する。
- 可能な経路では固定時刻の連番フレームから生成し、実時間録画とは分ける。進捗・中止・容量見積もりと終了後の状態復元を提供する。
- 凡例、単位、物理時刻、変形倍率、暫定設定を出力へ含められるようにする。

## 保存とエージェント操作

再現できるビュー設定にカメラ、レイヤー、色範囲、断面、シード、時間範囲、注記を保存し、結果IDと版に結び付ける。API/MCPは表示能力取得、プリセット適用、ビュー設定、測定、時間指定、出力準備、出力実行・進捗・中止を扱う案とする。

エージェントは「内部の圧力差が分かる断面動画」「同じ色範囲で設計案を比較」などの意図から設定する。結果JSONとCSV等の数値出力も維持し、動画だけで検証を完結しない。共有用のインタラクティブ結果パッケージは、結果・ビュー設定・実行に必要なビューアを含む案として検討する。モデルや結果を公開する操作は別途扱う。

## 実装順序と検証

1. レイヤー制御、色範囲固定、表示プリセット、カメラとビュー設定保存。
2. 時間範囲選択と固定フレーム出力、MP4/GIFの対応検出・代替経路。
3. 流体矢印、断面等高線、定常流線と粒子表示。
4. 時系列速度場による粒子軌跡、等値面、同期ケース比較、共有パッケージ。

一定速度・既知圧力場で矢印方向・大きさ・単位と等高線を確認する。定常流線と非定常軌跡を別に検証する。動画のフレーム数・時間範囲・カメラ・色範囲・倍率、出力失敗/中止時の復元を確認する。大規模結果は間引きとWorker処理を利用し、描画・出力の時間とピークメモリを計測する。
