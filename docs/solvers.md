# ソルバー候補と選択方式

[English](en/solvers.md)

## 現在の実装と今後の候補

現在の選択肢はAirpocketと、線形・等方・Tet4構造のMFEM WASM。CPU/WebGPUと材料・分野の組合せには個別制限がある。以下の「同じ解析でソルバーを選ぶ」は追加アダプター検証後の目標であり、現在の選択可能一覧ではない。追加移植は[開発計画](roadmap.md)のP0〜P5の必須条件にしない。

2026-10-13時点の公式資料に基づく候補。ここにある機能は製品側の概要であり、本アプリでの対応保証ではない。各アダプターの版・要素・材料則・境界条件を検証後に対応を公開する。

|候補|役割・分野|導入順|注意点|
|---|---|---|---|
|CalculiX|線形・非線形構造、静的・動的・熱|追加構造候補|材料則と要素の組み合わせを個別検証|
|Elmer FEM|熱伝導、構造、流体、複数物理場|熱の主候補、構造の比較候補|方程式・境界条件ごとにアダプターを実装|
|Code_Aster|構造、熱、非線形、疲労・破壊|高度な構造の候補|専門的設定が多いため初期対象を限定|
|OpenFOAM Foundation版|流体、流体・固体の熱伝達|流体の主候補|有限体積法。FEM専用アプリとは呼ばない。配布系統と版を固定|
|Gmsh|CAD読み込み、メッシュ生成|共通基盤|解析ソルバーではない。流体境界層等には別メッシュ経路も必要|

## 同じ解析でソルバーを選ぶ

- 線形静解析: CalculiX / Elmer / Code_Aster のうち検証済みアダプターを選択。
- 固体の熱伝導: Elmer / CalculiX / Code_Aster の検証済み範囲から選択。
- 流体: OpenFOAM / Elmer の共通対応範囲のみ選択可能。
- ゴム、大変形、接触、損傷などは材料・要素・解析条件まで照合し、未対応ソルバーには理由を表示。
- 自動選択は理由を表示。失敗時に別ソルバーへ無断で切り替えない。
- 登録状態を「候補」「アダプター実装済み」「検証済み」に分離し、ローカル導入の有無も別に表示。
- 設定は共通モデルとソルバー固有設定を分け、ソルバー変更時に変換できない条件を列挙。
- 比較は形状、荷重、材料、境界条件、単位、収束条件を揃える。メッシュ変換や要素差も記録。点の最大応力だけで同等性を判定しない。

## 実行・配布

音響はElmerのHelmholtzモデルを最初の候補とする。Code_Asterは音響・構造連成の追加候補として対象モデルの検証から開始。CalculiXは部品の固有振動・構造応答側の候補であり、空気中の音圧解析まで同じ対応範囲とはしない。詳細は acoustics.md。

配布方針をGitHub Pages + ブラウザ内WASM実行へ変更。上記はネイティブOSSの機能候補であり、WASM実行可能という意味ではない。CalculiX、Elmer、Code_Aster、OpenFOAMはそれぞれ依存ライブラリ、言語・ビルド環境、ファイルI/O、並列実行、メモリ、ライセンスを調査し、ブラウザでの小規模例題を検証してから採用する。移植困難なソルバーは候補のまま残し、実行できる選択肢には出さない。詳細は browser-runtime.md。

外部実行であってもライセンス確認は必要。アプリのライセンス、ソルバー同梱の可否、再配布物のソース提供・通知義務を導入時に記録する。MFEMとAirpocketの実行ファイルを配布し、ライセンス・通知・再現可能なビルド手順を記録済み。他の候補は同梱しない。
