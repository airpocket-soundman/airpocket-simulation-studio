# 解析断面と測定

「内部を見る」で断面表示を有効にし、X/Y/Z方向と位置（mm）、残す側を設定します。結果表示の「断面に計算結果を表示」で内部の計算場を表示します。温度、変位、流速、音圧などは四面体の形状関数で補間します。応力・熱流束の色は節点平均による表示値です。測定はその四面体の値を使用するため、色の平均値と異なる場合があります。

「測定」で断面または結果表面をクリックすると、その位置の値を表示します。変形倍率を掛けた表示でも元のモデル座標に戻して測定します。過渡音は選択時刻の瞬時音圧、固有振動は選択モードの周波数と正規化変位です。モード変位は最大1 mmの正規化であり、実際の振動振幅ではありません。

切断面は表示用で、荷重や拘束を設定するCAD面ではありません。元の境界面と一致する断面は重複表示しません。内部断面生成はCPUで行い、大規模メッシュでは位置変更に時間が掛かります。

検証: `tests/result-slice.test.mjs` は断面積、線形場の補間、共有面重複、変形座標の逆対応を確認します。`tests/probe.test.mjs` は過渡音・モード・共有面の四面体指定を確認します。ブラウザの内部流路断面とクリック測定も確認します。

## 保存フレーム間の補間表示（GUI）

過渡音響の結果には、保存フレーム用の`#acoustic-time-frame`に加え、微調整スライダー`#acoustic-time-fine`（保存範囲を1000分割）と再生/一時停止`#acoustic-time-play`があります。保存フレーム間の時刻では音圧を線形補間して表示し、「補間表示」と明記します。外挿はせず、色範囲・物理配列・保存結果は変わりません。`setResultView`と画像・動画出力は従来どおり保存フレームのみです。純粋関数は`src/time-interpolation.js`（[過渡音響](transient-acoustics.md)）。
