# 固有振動解析

[English](en/modal-analysis.md)

「固有振動サンプル」は10 × 10 × 80 mmの片持ち部品の低次モードを計算します。固定位置、線形弾性定数、密度と形状から、固有振動数・振動形状を求めます。表示モードを選び、3D上で回転して確認し、解析ケースに保存できます。

## モデル・検証

`K φ = ω² M φ`。Kは既存の線形弾性Tet4剛性、Mは各節点へ `ρV/4` を割り当てる集中質量で、3方向に同じ質量を使います。拘束の局所座標基底は静解析と共通。非ゼロ荷重、非ゼロ指定変位、重力、熱応力、超弾性、適応解析は拒否します。拘束不足で剛体モードが残るモデルも拒否します。

ブロック逆反復、質量内積での2回直交化、Rayleigh–Ritzの小さな対称固有値問題を反復。指定モード数より2本多くのベクトルを使い、近接モードを同時に追跡します。剛性の逆作用は倍精度PCG（1e−10）で計算し、固有対の自由自由度残差 `||Kφ−λMφ|| / ||λMφ|| ≤ 1e−5` を確認します。未収束モードは結果として返しません。

テストでは、片持ち梁の低次曲げモードをEuler–Bernoulliの `β₁²/(2πL²) √(EI/(ρA))` と比較し、メッシュ細分化で誤差が減ること、近接する曲げモード、Eを4倍すると振動数が2倍、密度を4倍すると1/2、JS/WASM一致を検査します。梁の参照式と3D固体の解は完全には同一でありません。固有残差は離散問題の検証であり、メッシュ誤差の保証ではありません。

固有振動の一般化固有値問題の例: [MFEM 4.10 Example 12](https://docs.mfem.org/4.10/ex12p_8cpp_source.html)。本機能はAirpocketの部分空間反復で、MFEM/HYPREのLOBPCGを移植したものではありません。

## 入力・出力と限界

共通APIの `study.kind: 'structural'` に `modalAnalysis: true`、`modeCount`（1〜6）、`modalIterations`（1〜100、標準60）を設定。線形物性に正の `density`（kg/m³）が必要。UIで物性を登録してから解析します。結果種別は `modal`。各 `modes` の `frequencyHz`、`residual`、`displacement`、`magnitudes` を保存します。

モードは表示用に最大変位1 mmへ正規化。固有ベクトルの符号と、完全重複モードの基底には任意性があります。この変位は荷重を受けたときの応答振幅ではありません。現段階では音圧への連成、強制振動、減衰、予応力、自由支持の剛体モード、接触、混合非圧縮要素を含みません。CPU/JSとCPU/WASMのみ、2,000節点・8,000四面体まで。MFEMとGPUの固有値計算は未接続です。
