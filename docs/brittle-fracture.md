# 欠陥を指定した脆性破壊評価

[English](en/brittle-fracture.md)

v0.42は、線形弾性解析で得た公称応力から、指定した欠陥のモードI応力拡大係数を評価します。き裂のある形状をメッシュ化して解く機能ではありません。き裂面の法線をnとして、垂直応力σ = nᵀSnに指定した残留垂直応力を加え、引張成分だけを使います。

`KI = Y max(0, σ + σresidual) √(π a)`

長さaは計算時にmmからmへ変換します。靱性は画面ではMPa√m、保存データではPa√mです。Yとaの定義はき裂形状に依存します。無限板の中央き裂ではY=1、aは全き裂長の半分です。表面き裂や有限幅板で同じ値を自動採用してはいけません。形状係数の根拠と、公称応力が欠陥の範囲で代表値として使える条件を記録してください。式と適用の基礎は[AFGROW DTD Handbook](https://www.afgrow.net/applications/DTDHandbook/sections/page2_2_1.aspx)を参照しています。

## 操作

1. 「脆性材料の破壊靱性」に靱性の上下限、試験温度範囲、出典、試験条件、表面状態を登録します。
2. 線形構造を解析します。物性評価温度が靱性の試験温度範囲内でなければ評価できません。
3. 「欠陥を指定して脆性破壊を評価」で、欠陥寸法a・形状係数Y・残留垂直応力の上下限、長さ1のき裂面法線、根拠を指定します。
4. 「表示結果を脆性破壊評価」を実行します。ケースに保存すると、入力条件と評価結果を一緒に保存できます。

表面状態は試験値を適用できるかの記録です。粗さや傷を文章で入力しても、靱性や欠陥寸法を自動補正しません。ガラスでは表面欠陥と環境によるき裂成長が重要であることを[NISTの解説](https://nvlpubs.nist.gov/nistpubs/sp958-lide/html/181-183.html)で確認しています。材料名や一般的な強度だけではこの評価を実行できません。

## 上下限の意味

KI下限は最小a・Y・残留応力、上限はそれぞれの最大値で計算します。KI/KICの下限には最大靱性、上限には最小靱性を使います。全四面体の公称応力を評価するスクリーニングで、現実の欠陥が全ての要素に存在するという確率モデルではありません。

- 上限が1未満: 入力した上下限の範囲で「靱性未満」。安全や寿命の保証ではありません。
- 下限が1未満で上限が1以上: 「境界をまたぐ」。入力の不確実性で判定が変わります。
- 下限が1以上: 入力した上下限の範囲で「靱性に到達」。き裂進展の計算や最終破断の保証ではありません。

要素ごとの臨界欠陥寸法は`a_critical = (KIC / (Y σopening))² / π`から計算し、mmで保存します。引張開口が0のときの無限大はJSONの`null`で表します。上下限は確率分布、信頼区間、Weibull破壊確率ではありません。温度補間は行いません。

## 検証と制限

「架空の脆性破壊参照サンプル」は10×10×40 mmの棒、E=1 GPa、ν=0、100 Nで公称応力1 MPaの参照です。実材料のガラスデータではありません。架空靱性0.02〜0.03 MPa√m、a=0.1〜0.4 mm、Y=1、残留応力0では、KI/KICの範囲は0.59081795〜1.77245385、臨界寸法は0.12732395〜0.28647890 mmです。

参照式、圧縮閉口、方向回転、残留応力・Y・aの感度、温度範囲、実WASM解析、保存復元と改変拒否を検証します。保存された評価は、保存応力・靱性・欠陥条件から再計算して照合します。FE応力そのものの実験妥当性を保証する検査ではありません。

静的な小ひずみ線形弾性のモードIに限定します。指定したき裂面のせん断牽引が応力成分最大値の`1e-5`を超える混合モードは拒否します。塑性・超弾性・熱応力・固有振動結果は拒否します。応力腐食、低速き裂成長、疲労寿命、Weibull統計、き裂相互作用・進展、残留応力の深さ分布は未対応です。特異点や応力勾配が大きい場所には、別のき裂解析と測定が必要です。

共通APIは`evaluateFracture(result, properties, options)`、Workerは`options.fractureAssessment`、画面のAPIは`window.analysisApi.evaluateFracture(options)`です。`properties.fractureData`に試験データを登録してください。
