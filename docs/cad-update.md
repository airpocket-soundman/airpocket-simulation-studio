# STEP更新と条件の照合

[English](en/cad-update.md)

v0.41では、元のSTEPを読み込んだプロジェクトから「CADを更新して条件を照合」を開き、更新したSTEPを選択できます。読込と照合だけでは現在のモデルは変えません。条件ごとの照合結果を確認し、「照合結果を適用」で新しいモデルへ切り替えます。材料、荷重・温度などの条件値、方向・局所座標、解析設定、局所メッシュ設定を保持し、現在の解析結果は解除します。保存済みのケースには元の入力と結果が残ります。

面番号や部品の順番には依存せず、表示面の場所・面積・重心・向きと形状を比較します。平面は輪郭ループを比較し、直線上の中間頂点を除いて三角形の再分割にも対応します。曲面は同じ向きと頂点を持つ表示三角形の集合が一致する場合に照合します。部分選択は選択した三角形を再現できる場合だけ引き継ぎ、寸法指定は親面が一致し、保存寸法で領域を再現できる場合に引き継ぎます。同じ場所に重複する面、面の分割・統合、形状変更、再分割で再現できなくなった部分選択には、面番号での代用を行いません。

## 未解決条件を修復する

照合できない条件は削除せず、値と方向を保持した未解決条件にします。一つの条件が複数面を使う場合は、全ての領域を照合できなければその条件全体を未解決にします。

1. 新しいモデルで領域を選び直します。
2. 該当する条件の「選択範囲で更新」を押します。
3. 全ての未解決条件を修復してから解析します。

未解決状態でもプロジェクトを書き出して保存・再読込できます。未解決中は解析ボタンを無効にし、ブラウザ側・Worker・境界転送・ケース保存でも解析を拒否します。条件の「削除」を利用者が選んだ場合は、その条件を除いた設定になります。メッシュの生成は可能です。

## 範囲と限界

元のSTEP表示面を対象にした幾何照合で、永続的なB-rep面IDやCADフィーチャ履歴の追跡ではありません。比較に使うのはアプリの表示三角形です。長さの許容差は各面の最大寸法を基準に`1e-7 × max(1, 面寸法mm)`、面積は相対`1e-6`です。表示精度より小さい変更、曲面の再分割、変形した面を同じ設計面として識別することは保証しません。対応が一意でない場合は再選択が必要です。

更新ファイルはSTEP/STP・50 MB以下、比較する表示CAD面は各モデル2000面までです。匿名面、STL、生成済みのGmsh表示面、流体領域の直接更新は対象外です。保存した温度場や振動源を連成している場合は、先に連成元を解除して更新後に再接続します。元の入力との整合を確認できないまま場を転用しません。

読込中や照合後にモデル・条件が変更された場合、古い照合結果は適用できません。更新STEPをもう一度選んで照合してください。

共通APIの`previewCadUpdate({name,sourceModel,meshes})`は現在のモデルを変更せず、条件別の`matched`／`needs-reselection`と件数を返します。`applyCadUpdate(...)`はその時点のモデルから再照合して適用します。`meshes`と`sourceModel.data`は同じSTEPから取得した表示面とBase64の元データを渡してください。未解決条件には`cadUpdateRequired`が付き、`replaceConditionRegion(index)`で新しい選択範囲を登録すると解除されます。

検証には面番号変更、平面再分割、部品順変更、消失・重複、同じ面積・重心・包絡を持つ異なる凹形状、部分選択、寸法指定、保存復元と解析拒否を含みます。実STEPの10×10×40 mmの棒を同じ形状で更新すると100 N・E=1 GPa・ν=0の変位は0.04 mm、長さ50 mmへ更新して荷重面を再選択すると0.05 mmです。
