# 開発順序と受け入れ条件

現状: フェーズ0の文書策定のみ完了。実装・実行検証は未着手。

|段階|成果|受け入れ条件|
|---|---|---|
|0 計画|要件、ソルバー候補、材料、構成|ユーザー要求との照合と優先順位の記録|
|1 3D領域指定|STEP表示、回転、面・曲面の部分選択、保存|平面・円筒・自由曲面で選択し、裏側誤選択を防止。寸法・面積と保存復元を確認|
|2 構造の縦通し|CalculiX、線形静解析、固定・部分面荷重、結果表示|片持ち梁のたわみ・反力、合力保存、単位変換、メッシュ収束。領域を再メッシュしても意図を維持|
|3 ソルバー選択・熱|Elmer、構造比較、定常・非定常熱|同条件の検証ケースでソルバー比較。一次元熱伝導・時間変化の参照解とエネルギー収支|
|4 非線形材料|金属塑性、ゴム超弾性、樹脂の必要モデル、Code_Aster候補|各材料則・要素組み合わせを標準例題と試験曲線で確認。未対応の組み合わせは拒否|
|5 流体|OpenFOAM、流体領域、単相層流、結果|円管流の圧力損失、質量収支、メッシュ収束。入口・出口・壁の漏れ検出|
|6 拡張・連成|熱応力、共役熱伝達、乱流、接触等|転送とエネルギー収支、物理モデルごとの検証例|
|7 破壊・疲労|材料ごとの損傷・破壊評価|材料データ、破壊モデル、実験または公開ベンチマークで検証。ガラス等の不確実性も記録|

## 全段階に共通の完了条件

- ソルバーの存在だけで対応済みとしない。入力生成、実行、結果読込、収束判定まで通す。
- 検証ケースごとに参照値、誤差許容値の根拠、ソルバー版、メッシュ条件、実測誤差を記録。
- 不足物性、未拘束、領域消失、低品質メッシュ、未対応条件、計算失敗を識別。
- 初心者が3D操作から条件指定・結果確認まで実行できる操作確認。

## 次の着手点

音響の追加順: フェーズ3以降に閉じた音響領域の周波数応答・共鳴をElmerで試作し、矩形空洞・管の参照解と照合。フェーズ4以降に構造の周波数応答、フェーズ6以降に振動音響連成・外部放射を追加する。波長に対するメッシュ収束、減衰、境界反射、音圧の基準値と振幅規約を検証する。流体騒音と聴ける音への変換は後続の別マイルストーンとする。

フェーズ1: STEPのCAD面と表示三角形の対応、および曲面の部分選択を最優先で試作する。ここを成立させてから計算ワーカーを接続する。
