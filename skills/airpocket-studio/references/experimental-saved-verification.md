# Experimental saved verification

Use these workflows only when relevant to the user's engineering task. Discover the actual registered tools first. Missing repository tools may be called through the documented local repository `callStudioTool` fallback; report that environment explicitly. Never claim an installed server was upgraded automatically. All paths below are absolute and outputs must be new files.

- `studio_compare_printed_holdout({request,output})`: request JSON explicitly supplies training/validation paths and raw SHA-256 values, all identification options and a complete disjoint specimen mapping. Fits training only and computes Pa errors. Calibration, physical independence and accuracy remain unverified; comparison success is not accuracy acceptance. Request64KiB, each dataset2,000,000bytes,100pairs/10,000samples, artifact4MiB. CLI: `scripts/compare-printed-holdout.mjs`.
- `studio_roundtrip_printed_sls({config,configSha256,output})`: synthetic-only config explicitly supplies both source hashes, SLS options/mapping, bulk modulus K, finite ramp and worker deadline up to30s. It converts the fitted Young relaxation to shear Prony parameters and reports finite-ramp/small-amplitude discrepancies in Pa, never exact finite-strain reproduction or inferred bulk properties. Maximum8pairs/4,096driver steps. CLI: `scripts/roundtrip-printed-sls.mjs`.
- `studio_run_fsi_average({request,output})`: explicitly synthetic, x-uniform tangential channel/plate configuration with a time-averaged force/midpoint protocol. Bounded2,000,000cell steps and120s worker deadline. Reports work/dissipation/momentum diagnostics, not general ALE/pressure/nonlinear FSI or physical calibration. CLI: `scripts/run-fsi-average.mjs`.

The file services retain source hashes, confirm owned worker exit and private output-stream closure, and publish complete artifacts exclusively. They return compact summaries; inspect saved artifacts deliberately rather than fetching all curves by default. Worker stdout/stderr is isolated; unexpected output is refused. Direct Node APIs and CLIs support cancellation; these synchronous stdio calls do not advertise a separate cancellation notification. File IO and total process RSS are not bounded by the worker deadline/memory claim. No browser permission, input or material is modified.

For an explicitly requested high-order static elasticity calculation, `studio_start_analysis` accepts `elementOrder:2`, `method:'pcg-strict'`, `adaptive:false`. Inspect `studio_capabilities.tet10SavedJobs` first. The current profile requires one explicit box, whole axis-aligned fixed/uniform-force faces, explicit gravity false and isotropic constants; limits are512parent tetrahedra/4,096quadratic nodes. It runs JavaScript CPU under worker/process isolation, not native machine code. Preserve the full `elastic-tet10` / `straight-affine-Tet10-native-v1` saved result and its revision. Case views, point probes and common case comparison explicitly refuse this representation: do not downsample to Tet4 or claim P5B design-loop acceptance from this job alone.
