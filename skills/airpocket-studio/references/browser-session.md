### Inspect this browser's GPU

Discover `checkGpuEnvironment` with `studio_browser_contracts({method:"checkGpuEnvironment"})`, then invoke it through an inspect-scoped browser session with `args:{}`. The response identifies `target:"browser"`; `declaredCapability.declarationOnly` describes the implemented probe, while `observation` reports a fresh request for a WebGPU adapter/device in that paired browser. `observation.available:false` can mean the browser has no WebGPU API, no adapter, or the device request failed. `isFallbackAdapter` distinguishes an explicitly reported software fallback from an actual GPU; `null` means the browser did not identify it. The probe destroys its temporary device before returning and does not read or change project/result data. This is not a Node runtime capability check and does not prove that a later solver job will use WebGPU. A missing browser adapter method means this deployment does not expose the probe.

Disconnect cancels connection-owned jobs. Restart recovery is unsupported; optional browser field retention is described below. Public HTTPS-to-loopback connectivity/permissions remain unverified. Commands time out after 15 seconds: inspect before retrying mutations. See `docs/automation.md` for scopes and contracts.

With `includeFields:true` on a browser startJob, read `artifact.artifactId` from jobEvents and call `jobArtifact({jobId,artifactId,point?,bodyIndex?,elementIndex?,offset?,limit?})`. Keep pages <=200; request summary/point instead of downloading complete arrays. Mesh/field hashes, input revision, units and physical seconds or load-step metadata are checked; intermediate values always remain provisional even after the job succeeds. Default shared serialized retention is 64 MB, not a heap-memory guarantee. Limits preserve summaries; malformed observations emit observation-error. Release retained jobs only when releaseAllowed:true (terminal and executionSettled:true) to return their retention allocation. Thermal/transient-acoustic scalars and plasticity/hyperelastic step displacement vectors are supported; other solvers may provide stage/iteration summaries only.

## Connection diagnostics

If pairing fails, use **Diagnose connection** without entering a code. The bounded GET `/health` probe sends no credentials and reports reachability separately from authentication; permission-query status is advisory and `denied` does not establish that the user refused a prompt. A successful health probe grants no scope and creates no session. Use `studio_browser_sessions({diagnostics:true})` for bounded bridge counters; omitted/false retains `{sessions}`. Zero requests means this bridge observed none, not a proven browser/network cause. Diagnostics retain only configured Origin/endpoint, counters and session count, never received URLs/Origins, headers, tokens or model data. Do not enable security bypass flags, silently grant browser permissions, or expand application scopes.
